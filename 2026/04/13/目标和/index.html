494. 目标和

🎯 问题描述

描述：给定一个非负整数数组 nums 和一个目标整数 target，对于数组中的每个数字，可以选择给它添加 ‘+’ 或 ‘-’ 符号。返回可以使最终数组和等于目标值 target 的表达式数目。

说明：

  • 给定数组非空，且包含非负整数
  • 数组长度 n ≤ 20
  • 数组中数字总和 ≤ 1000
  • 目标值 -1000 ≤ target ≤ 1000

💻 解题思路

思路1：记忆化搜索（递归DP）

核心思想：这是一个典型的子集划分问题，可以通过递归枚举所有可能的符号组合来解决。

问题转化：

  • 设所有添加 ‘+’ 的数字之和为 P，所有添加 ‘-’ 的数字之和为 N
  • 我们需要 P - N = target
  • 同时 P + N = sum(nums)
  • 推导出：P = (target + sum(nums)) / 2
  • 问题转化为：从数组中选出若干数字，使其和等于 P 的方案数

算法步骤：

  1. 递归定义：f(i, sum) 表示从第 i 个位置开始，当前和为 sum 时，能达到目标值的方案数
  2. 基准情况：当 i == n 时，检查当前和是否等于目标值
  3. 递归拆解：对当前数字，可以选择加 ‘+’ 或 ‘-’
  4. 记忆化：使用 @lru_cache 避免重复计算

思路1：代码实现

思路1：📊 性能分析

  • 时间复杂度：O(N×S)O(N \times S)O(N×S)
    • NNN 是数组长度
    • SSS 是可能的和的范围，由于记忆化，每个状态只计算一次
  • 空间复杂度：O(N×S)O(N \times S)O(N×S)
    • 递归栈深度为 O(N)O(N)O(N)
    • 记忆化缓存空间为 O(N×S)O(N \times S)O(N×S)

🔍 关键点分析

1. 记忆化搜索的必要性

  • 朴素递归会产生大量重复计算，时间复杂度为 O(2N)O(2^N)O(2N)
  • 使用 @lru_cache 可以将时间复杂度优化到 O(N×S)O(N \times S)O(N×S)

2. 边界条件处理

  • 当 target + sum(nums) 为奇数时，无解
  • 当 abs(target) > sum(nums) 时，无解

3. 状态压缩技巧

  • 在背包解法中，可以使用一维数组优化空间复杂度
  • 逆序遍历避免重复使用同一物品
