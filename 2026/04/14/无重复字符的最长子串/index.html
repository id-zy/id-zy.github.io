3. 无重复字符的最长子串

🎯 问题描述（来源于LeetCode）

描述：
给定一个字符串 s，请你找出其中不含有重复字符的 最长子串 的长度。

说明：

  • 子串：字符串中一段连续非空的字符序列。

  • 核心逻辑：使用滑动窗口维护一个“无重复字符”的区间。当遇到重复字符时，收缩左边界，直到窗口内再次满足无重复条件。

思路1：📊 性能分析

  • 时间复杂度：O(N)O(N)O(N)
    • 其中 NNN 是字符串 s 的长度。
    • 虽然代码中有一个 while 循环嵌套在 for 循环中，但每个字符最多被访问两次（一次被右边界 right 加入，一次被左边界 left 移出）。因此，整体操作次数是线性的。
  • 空间复杂度：O(min⁡(M,N))O(\min(M, N))O(min(M,N))
    • 其中 MMM 是字符集的大小（例如 ASCII 字符集大小为 128）。
    • 哈希表 cnt 最多存储 MMM 个字符的计数。如果字符集很大，则受限于字符串长度 NNN。

思考

  1. 不定长窗口：

    • 与之前的定长窗口不同，这里的窗口大小是动态变化的。
    • 右边界 right 始终向右移动。
    • 左边界 left 只有在遇到重复字符（cnt[c] > 1）时才会向右移动。

  2. 收缩逻辑：

    • while cnt[c] > 1: 是核心。它保证了在任何时刻，窗口内的所有字符出现次数都不超过 1。
    • 当发现重复字符 c 时，我们不断移除左边的字符，直到那个重复的 c 被移除一个为止。

  3. 答案更新时机：

    • ans = max(ans, right - left + 1) 放在 while 循环之后。
    • 这保证了我们只在窗口满足“无重复字符”这一合法条件时，才去更新最大长度。

  4. Counter 的使用：

    • 使用 collections.Counter 可以方便地处理字符计数，比普通的字典操作更简洁（例如不需要判断键是否存在）。
