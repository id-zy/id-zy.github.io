1814. 统计一个数组中好对子的个数

🎯 问题描述

描述：
给你一个非负整数数组 nums。
如果满足 0 <= i < j < nums.length 且：

nums[i]+rev(nums[j])==nums[j]+rev(nums[i])nums[i] + rev(nums[j]) == nums[j] + rev(nums[i]) nums[i]+rev(nums[j])==nums[j]+rev(nums[i])

那么我们称 (i, j) 是一个好对子。
其中 rev(x) 表示将整数 x 的各位数字反转（例如 rev(123) = 321，rev(120) = 21）。
请你返回好对子的数目。由于答案可能很大，请返回它对 109+710^9 + 7109+7 取余的结果。

说明：

  • 这是一个哈希表计数结合数学恒等变形的问题。

  • 核心难点：直接暴力枚举所有 (i, j) 对需要 O(N2)O(N^2)O(N2) 时间，效率太低。

  • 策略：通过移项变形，将涉及 i 和 j 的项分离，找到每个元素独立的特征值（差值），将问题转化为“寻找具有相同特征值的元素对”。

💻 解题思路

思路1：数学变换 + 哈希表计数

核心逻辑

  1. 公式变形：
    原条件：nums[i]+rev(nums[j])==nums[j]+rev(nums[i])nums[i] + rev(nums[j]) == nums[j] + rev(nums[i])nums[i]+rev(nums[j])==nums[j]+rev(nums[i])
    移项得：nums[i]−rev(nums[i])==nums[j]−rev(nums[j])nums[i] - rev(nums[i]) == nums[j] - rev(nums[j])nums[i]−rev(nums[i])==nums[j]−rev(nums[j])
  2. 特征提取：
    定义一个元素的特征值为 diff=val−rev(val)diff = val - rev(val)diff=val−rev(val)。
    如果两个元素的下标 i<ji < ji<j 且它们的特征值 diffdiffdiff 相等，那么它们就构成一个好对子。
  3. 计数策略：
    遍历数组，对于每个元素计算其 diffdiffdiff。
    • 如果这个 diffdiffdiff 之前出现过 kkk 次，说明当前元素可以和之前的 kkk 个元素分别组成好对子，答案增加 kkk。
    • 然后将当前 diffdiffdiff 的计数加 1。

代码实现

📊 性能分析

  • 时间复杂度：O(N×log⁡M)O(N \times \log M)O(N×logM)
    • 其中 NNN 是数组长度，MMM 是数组中的最大值。
    • 遍历数组需要 O(N)O(N)O(N)。
    • 每次计算反转 int(str(num)[::-1]) 需要 O(log⁡10M)O(\log_{10} M)O(log10​M) 的时间（数字的位数）。
    • 哈希表操作平均为 O(1)O(1)O(1)。
  • 空间复杂度：O(N)O(N)O(N)
    • 哈希表 count 在最坏情况下存储 NNN 个不同的差分值。

思考

  1. 数学变换的重要性：

    • 这是解题的关键。如果不进行移项，我们无法将 iii 和 jjj 的贡献分离开来独立计算。
    • 变换后，问题变成了“寻找具有相同属性（差分）的元素对”，这是哈希表的经典应用场景。

  2. 累加计数的原理：

    • 代码使用了 ans += count[diff]。
    • 假设某个差分值 DDD 之前出现了 kkk 次（下标为 p1,p2,...,pkp_1, p_2, ..., p_kp1​,p2​,...,pk​）。
    • 当前遇到了下标 jjj，且 diffj=Ddiff_j = Ddiffj​=D。
    • 因为 p1<p2<...<pk<jp_1 < p_2 < ... < p_k < jp1​<p2​<...<pk​<j，所以 (p1,j),(p2,j),...,(pk,j)(p_1, j), (p_2, j), ..., (p_k, j)(p1​,j),(p2​,j),...,(pk​,j) 都是合法的好对子。
    • 一共增加了 kkk 对。

  3. 反转操作的实现：

    • int(str(num)[::-1]) 是 Python 中反转整数的常用技巧。
    • 它先将数字转为字符串，利用切片 [::-1] 反转字符串，再转回整数。
    • 这种方法简单且不易出错（自动处理前导零，如 120 反转为 21）。

  4. 取模运算：

    • 题目要求对 109+710^9 + 7109+7 取模。
    • 由于答案可能很大（最坏情况是 N(N−1)/2N(N-1)/2N(N−1)/2），需要在返回时取模。
    • 也可以在每次 ans += ... 时取模，防止溢出（虽然在 Python 中整数不会溢出，但在其他语言中需要注意）。

  5. 边界情况：

    • 数组长度为 1：无法组成数对，返回 0。
    • 所有数字都相同：例如 [5, 5, 5]。5 - 5 = 0。所有差分都为 0。对数为 C32=3C_3^2 = 3C32​=3。
    • 没有好对子：所有差分都不同，返回 0。
