1749. 任意子数组和的绝对值的最大值

🎯 问题描述

描述：
给你一个整数数组 nums。
子数组 nums[l...r] 的和定义为 nums[l]+nums[l+1]+...+nums[r]nums[l] + nums[l+1] + ... + nums[r]nums[l]+nums[l+1]+...+nums[r]。
你需要找出所有可能的子数组和中，绝对值最大的那一个。
即求 max⁡(∣Sum(l,r)∣)\max(|Sum(l, r)|)max(∣Sum(l,r)∣)，其中 0≤l≤r<n0 \le l \le r < n0≤l≤r<n。

说明：

  • 这是一个前缀和结合数学推导的问题。

  • 核心策略：

    • 任意子数组的和都可以表示为两个前缀和之差：Sum(l,r)=pre[r+1]−pre[l]Sum(l, r) = pre[r+1] - pre[l]Sum(l,r)=pre[r+1]−pre[l]。
    • 我们要最大化 ∣pre[r+1]−pre[l]∣|pre[r+1] - pre[l]|∣pre[r+1]−pre[l]∣。
    • 这等价于在 pre 数组中找到两个数，使它们的差值的绝对值最大。
    • 显然，这个最大值等于 pre 数组中的最大值减去最小值。

💻 解题思路

思路1：前缀和极值差

核心逻辑

  1. 构建前缀和数组 pre：
    • pre[0] = 0（表示空前缀的和）。
    • pre[i+1] = pre[i] + nums[i]。
    • pre[i] 表示 nums[0] 到 nums[i-1] 的和。
  2. 数学转化：
    • 任意子数组 nums[l...r] 的和可以表示为 S=pre[r+1]−pre[l]S = pre[r+1] - pre[l]S=pre[r+1]−pre[l]。
    • 我们需要求 max⁡(∣S∣)=max⁡(∣pre[r+1]−pre[l]∣)\max(|S|) = \max(|pre[r+1] - pre[l]|)max(∣S∣)=max(∣pre[r+1]−pre[l]∣)。
    • 绝对值 ∣A−B∣|A - B|∣A−B∣ 的最大值，一定等于数组中的最大值减去最小值。
    • 即 max⁡(pre)−min⁡(pre)\max(pre) - \min(pre)max(pre)−min(pre)。
  3. 计算结果：
    • 直接返回 max(pre) - min(pre)。

📊 性能分析

  • 时间复杂度：O(N)O(N)O(N)
    • 构建前缀和数组：O(N)O(N)O(N)。
    • 查找最大值和最小值：O(N)O(N)O(N)。
    • 总体线性时间。
  • 空间复杂度：O(N)O(N)O(N)
    • 需要一个长度为 N+1N+1N+1 的 pre 数组。
    • 注：其实可以优化到 O(1)O(1)O(1) 空间，只需在遍历过程中维护当前的 min_pre 和 max_pre 即可，不需要存储整个数组。

思考

  1. 为什么 pre 数组要包含 0？

    • pre[0] = 0 代表空前缀。
    • 如果不包含 0，我们就无法表示从下标 0 开始的子数组（即 l=0 的情况）。
    • 例如，如果整个数组的和最大，那么 Sum(0,n−1)=pre[n]−pre[0]Sum(0, n-1) = pre[n] - pre[0]Sum(0,n−1)=pre[n]−pre[0]。

  2. 数学证明：

    • 我们要最大化 ∣x−y∣|x - y|∣x−y∣，其中 x,y∈prex, y \in prex,y∈pre。
    • 情况1：x≥yx \ge yx≥y，则 ∣x−y∣=x−y|x - y| = x - y∣x−y∣=x−y。要最大化它，需 xxx 最大，yyy 最小。
    • 情况2：x<yx < yx<y，则 ∣x−y∣=y−x|x - y| = y - x∣x−y∣=y−x。要最大化它，需 yyy 最大，xxx 最小。
    • 综上，最大值总是 max⁡(pre)−min⁡(pre)\max(pre) - \min(pre)max(pre)−min(pre)。

  3. 空间优化版本：

    • 由于我们只需要最大值和最小值，不需要回溯具体的子数组，因此不需要存储整个 pre 数组。

  4. 与最大子数组和的区别：

    • 最大子数组和（Kadane算法）只关心正数累积。
    • 本题关心绝对值，所以既要看最大的正累积，也要看最小的负累积（因为 ∣负数∣|负数|∣负数∣ 可能很大）。
