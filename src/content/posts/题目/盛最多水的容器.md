# 盛最多水的容器

> **难度**：中等 | **题号**：11 | **链接**：https://leetcode.cn/problems/container-with-most-water/ | **数据结构**：双指针 / 贪心

## 🎯 问题描述

**描述**：
给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。
找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水，返回容器可以储存的最大水量。
说明：你不能倾斜容器。

**示例 1**：

```text
输入：[1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。
     在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。
```

**示例 2**：

```text
输入：height = [1,1]
输出：1
```

**提示**：
- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

## 💻 解题思路

### 思路 1：双指针（从两端向内收缩，贪心移动短板）

#### 核心逻辑

容器面积公式：

```text
面积 = min(height[l], height[r]) * (r - l)
```

用两个指针 `l`、`r` 分别指向左右两端，初始宽度最大。每次比较两端高度：

- **只移动较矮的一端**（向内收一格）。
- 理由：宽度 `r - l` 只会越来越小；若移动**较高**的一端，新的高度上限仍受「短板（原来较矮的那端）」限制，面积**不可能变大**。只有换掉短板，才有可能遇到更高的柱子，从而让面积有机会增大。

#### 代码实现

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left = len(height) - 1      # 右边界
        right = 0                   # 左边界
        ans = 0
        while right < left:
            h = min(height[right], height[left])
            a = h * (left - right)
            ans = max(ans, a)
            if height[right] < height[left]:    # 移动较矮的一端
                right += 1
            else:
                left -= 1
        return ans
```

> 🔧 草稿里 `left` 实际指向**右端点**、`right` 指向**左端点**，命名与直觉相反（逻辑无误，此处保留原写法）。习惯上写成 `l, r = 0, n - 1` 更不易看错。

#### 📊 性能分析

- 时间复杂度：$O(n)$ —— 两指针共移动 $n - 1$ 次。
- 空间复杂度：$O(1)$ —— 只用常数个变量。

#### 思考

1. **为什么移动短板是安全的（贪心正确性）？** 设 `height[l] < height[r]`，此刻面积为 `height[l] * (r - l)`。若固定 `l` 去移动 `r`，宽度变小、高度又不会超过 `height[l]`，面积只会更小；所以「以 `l` 为边界的最优解」已经拿到，可以放心抛掉 `l`。
2. **双指针为什么能穷尽最优解？** 每轮都排除掉「不可能再产生更优解」的那一端，用 $O(n)$ 次排除覆盖全部候选解，而不是 $O(n^2)$ 枚举。
3. **与 接雨水 的区别**：都用「双指针 + 向内收缩」，但本题只挑**两根**柱子围成**一个**容器求最大面积；接雨水求的是**整个地形**能积的**雨水总量**。

## 📝 总结

**双指针贪心的入门代表作。** 一句话记住：**宽度只会变小，所以每次只能移动短板**。理解「为什么移动长板一定不会更优」，就理解了这道题的全部证明。
