# 180. 连续出现的数字

> **难度**：中等 | **题号**：180 | **链接**：[180. 连续出现的数字 - 力扣（LeetCode）](https://leetcode.cn/problems/consecutive-numbers/)

## 🎯 问题描述

**描述**：找出 Logs 表中**至少连续出现 3 次**的数字（按 id 顺序），返回去重结果。

**表：Logs**

```text
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| num         | varchar |
+-------------+---------+
```

**示例 1**：

```text
输入：
Logs 表:
+----+-----+
| id | num |
+----+-----+
| 1  | 1   |
| 2  | 1   |
| 3  | 1   |
| 4  | 2   |
| 5  | 1   |
| 6  | 2   |
| 7  | 2   |
+----+-----+
输出：
+----------------+
| ConsecutiveNums|
+----------------+
| 1              |
+----------------+
```

**提示**：

- "连续"要与"出现次数"区分开：必须按 id 相邻判断。
- 最后要 DISTINCT（连续段可能有多段同值）。

## 💻 解题思路

### 思路1：双 ROW_NUMBER 分组法（Gaps and Islands）

#### 核心逻辑

经典「间隙与孤岛」模型：`rn` 是按 num 分区内的序号，`global_rn` 是全局序号；同一个连续段内两者差值 `global_rn - rn` 恒定。按这个差值分组，段内行数 ≥ 3 即为连续 3 次。比自连接三次写法（`l1.num = l2.num and l2.num = l3.num and l1.id+1 = l2.id ...`）更通用、可扩展到连续 N 次。

#### 代码实现

```sql
SELECT DISTINCT num AS ConsecutiveNums
FROM (
SELECT
num,
ROW_NUMBER() OVER (PARTITION BY num ORDER BY id) AS rn,
ROW_NUMBER() OVER (ORDER BY id) AS global_rn
FROM Logs
) t
GROUP BY num, (global_rn - rn)
HAVING COUNT(*) >= 3;
```

#### 📊 性能分析

- 时间复杂度：$O(n \log n)$，两次窗口排序 + 一次聚合
- 空间复杂度：$O(n)$

#### 思考

- 该模型同样适用于「连续登录 N 天」类题（PARTITION BY uid, DATE_SUB(day, INTERVAL rn DAY)），与 SQL分析场景模板 的连续登录场景同源。

## 📝 总结

判断连续性：ROW_NUMBER 分区号差值分组（Gaps and Islands），段长 HAVING 过滤。
