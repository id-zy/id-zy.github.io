# 2486. 追加字符到字符串末尾使字符串成为另一个字符串的子序列

## 🎯 问题描述
**描述**：  
给你两个字符串 `s` 和 `t`，你可以在 `s` 的末尾追加任意数量的字符，使得 `t` 成为 `s` 的一个子序列。  
返回需要追加的最少字符数。

**说明**：  
- 子序列是指不改变字符相对顺序的情况下，从原字符串中删除若干字符后得到的新字符串。
- 追加的字符可以任意选择，只要最终 `t` 是 `s` 的子序列即可。

**示例**：

- 示例 1：

```text
输入: s = "coaching", t = "coding"
输出: 4
解释: 追加 "ding" 到 s 末尾，得到 "coachingding"，"coding" 是其子序列。
```

- 示例 2：

```text
输入: s = "abcde", t = "a"
输出: 0
解释: "a" 已经是 "abcde" 的子序列。
```

- 示例 3：

```text
输入: s = "z", t = "abcde"
输出: 5
```

## 💻 解题思路
### 思路：双指针（贪心匹配最长前缀）
#### 算法步骤
1. 初始化指针 `i = 0`，指向 `t` 的起始位置，`n = len(t)`。
2. 遍历字符串 `s` 中的每个字符 `ch`：
   - 如果 `i < n` 且 `ch == t[i]`，则 `i += 1`（成功匹配 `t` 的下一个字符）。
3. 遍历结束后，`i` 表示 `t` 中已经被 `s` 匹配到的字符数，即 `t` 在 `s` 中作为子序列的最长前缀长度。
4. 需要追加的字符数为 `n - i`，即 `t` 中未被匹配的剩余字符数。将这些字符按顺序追加到 `s` 末尾即可。
5. 返回 `n - i`。

#### 代码实现
```python
class Solution:
    def appendCharacters(self, s: str, t: str) -> int:
        i, n = 0, len(t)
        for ch in s:
            if i < n and ch == t[i]:
                i += 1
        return n - i
```

#### 📊 性能分析
- 时间复杂度：$O(len(s) + len(t))$，实际只遍历 `s` 一次，指针 `i` 最多移动 `len(t)` 次。
- 空间复杂度：$O(1)$，仅使用常数个变量。

#### 思考
贪心匹配是解决此类问题的最优策略：为了尽可能多地匹配 `t` 的前缀，我们在遍历 `s` 时，一旦当前字符等于 `t[i]`，就立即匹配（`i++`），因为跳过这个字符不会增加后续匹配的机会。因此该算法能正确找到 `t` 在 `s` 中作为子序列的最长前缀长度。最终答案即为剩余未匹配的字符数，直接追加即可。该解法简洁高效，是本题的标准解答。
