# 2540. 最小公共值

## 🎯 问题描述
**描述**：  
给定两个整数数组 `nums1` 和 `nums2`，它们已经按 **非递减顺序** 排序。  
请你返回两个数组的 **最小公共值** 。如果不存在这样的值，返回 `-1`。

**说明**：  
- 公共值是指同时出现在两个数组中的整数。
- 最小公共值指所有公共值中最小的那个。

**示例**：

- 示例 1：

```text
输入: nums1 = [1,2,3], nums2 = [2,4]
输出: 2
解释: 公共值只有 2，因此返回 2。
```

- 示例 2：

```text
输入: nums1 = [1,2,3,6], nums2 = [2,3,4,5]
输出: 2
解释: 公共值为 2 和 3，最小的是 2。
```

## 💻 解题思路
### 思路：双指针（归并思想）
#### 算法步骤
1. 初始化两个指针 `i1 = 0` 和 `i2 = 0`，分别指向两个数组的起始位置。
2. 当 `i1 < len(nums1)` 且 `i2 < len(nums2)` 时：
   - 如果 `nums1[i1] < nums2[i2]`，则 `i1` 右移一位。
   - 如果 `nums1[i1] > nums2[i2]`，则 `i2` 右移一位。
   - 如果两者相等，说明找到了公共值，由于数组非递减，且指针从前往后移动，第一次找到的一定是最小的公共值，直接返回该值。
3. 若循环结束仍未找到，返回 `-1`。

#### 代码实现
```python
from typing import List

class Solution:
    def getCommon(self, nums1: List[int], nums2: List[int]) -> int:
        i1 = i2 = 0
        l1, l2 = len(nums1), len(nums2)
        while i1 < l1 and i2 < l2:
            if nums1[i1] < nums2[i2]:
                i1 += 1
            elif nums1[i1] == nums2[i2]:
                return nums1[i1]
            else:
                i2 += 1
        return -1
```

#### 📊 性能分析
- 时间复杂度：$O(n + m)$，其中 $n$ 和 $m$ 分别是两个数组的长度，每个指针最多移动各自数组长度次。
- 空间复杂度：$O(1)$，仅使用常数个变量。

#### 思考
您的解法利用了两个数组均有序的性质，通过双指针逐步比较，跳过较小的元素，从而在线性时间内找到最小公共值。由于数组有序，第一次遇到的相等元素必然是全局最小公共值，因此可以直接返回。这是该问题的最优解法，代码简洁高效。
