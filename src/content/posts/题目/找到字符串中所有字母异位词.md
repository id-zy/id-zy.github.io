# 找到字符串中所有字母异位词

> **难度**：中等 | **题号**：438 | **链接**：https://leetcode.cn/problems/find-all-anagrams-in-a-string/ | **数据结构**：滑动窗口 / 哈希表

## 🎯 问题描述

**描述**：
给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。
异位词 指由相同字母重排列形成的字符串（包括相同的字符串）。

**示例 1**：

```text
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
解释：
起始索引等于 0 的子串是 "cba"，它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac"，它是 "abc" 的异位词。
```

**示例 2**：

```text
输入：s = "abab", p = "ab"
输出：[0,1,2]
```

**提示**：
- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母

## 💻 解题思路

### 思路 1：定长滑动窗口 + 字符计数比较

#### 核心逻辑

`p` 的所有异位词**长度都等于 `len(p)`**，所以问题等价于：在 `s` 上滑动一个**固定长度**的窗口，每次判断「窗口内的字符计数是否等于 `p` 的字符计数」。

- `cnt_p = Counter(p)`：目标频次。
- `cnt_s`：当前窗口的字符频次。右端滑入时 `+1`。
- 当窗口长度达到 `len(p)` 后（即 `left = right - len(p) + 1 >= 0`）：先比较 `cnt_s == cnt_p`，记录左端点，再把窗口**左端字符滑出**（`cnt_s[s[left]] -= 1`）。

#### 代码实现

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        cnt_p = Counter(p)
        cnt_s = Counter()
        ans = []

        for right, c in enumerate(s):
            cnt_s[c] += 1               # 右端滑入
            left = right - len(p) + 1
            if left < 0:                # 窗口还没长到 len(p)
                continue
            if cnt_s == cnt_p:          # 窗口内字符计数与 p 一致
                ans.append(left)
            cnt_s[s[left]] -= 1         # 左端滑出

        return ans
```

#### 📊 性能分析

- 时间复杂度：$O(n)$ —— 窗口滑动 $O(n)$；每次比较两个 Counter 的代价是字符集大小（本题固定 26），属常数级。
- 空间复杂度：$O(1)$ —— 两个计数器的规模受字符集限制（26），与 $n$ 无关；返回的答案数组最多 $O(n)$。

#### 思考

1. **Counter 相等性的隐藏福利（实测验证）**：`Counter({'a': 0}) == Counter()` 返回 **True** —— Counter 的相等判断把「计数为 0 的键」视作不存在。所以滑出时 `cnt_s[s[left]] -= 1` 减到 0 后**无需手动 `del`**，比较依旧正确。（注意边界：一旦计数变成**负数**就会破坏相等判断；本题只对已入窗口的字符做减法，不会出现负值。）
2. **定长滑窗 vs 可变长滑窗**：本题窗口大小恒为 `len(p)`，属于「定长滑窗」模板；对比 长度最小的子数组 是「可变长滑窗」。
3. **与 字母异位词分组 的关系**：分组用「排序后的 key」建等价类；本题需要在长串上**逐窗口**比较，用「字符计数」更快也更自然。

## 📝 总结

**定长滑窗 + Counter 比较**是「在串上找某种定长模式」的标准解法。要点：窗口只进一次出一次，所以整体 $O(n)$；用 Counter 相等性判断「窗口是否为某个串的异位词」，并利用「计数归零不影响相等」省掉清理动作。滑窗家族已串起：定长（本题）→ 可变长（长度最小的子数组）→ 无重复（无重复字符的最长子串）。
