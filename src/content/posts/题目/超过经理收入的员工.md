# 181. 超过经理收入的员工

> **难度**：简单 | **题号**：181 | **链接**：[181. 超过经理收入的员工 - 力扣（LeetCode）](https://leetcode.cn/problems/employees-earning-more-than-their-managers/)

## 🎯 问题描述

**描述**：找出 Employee 表中薪水**高于其经理**的员工，返回员工姓名。

**表：Employee**

```text
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| name        | varchar |
| salary      | int     |
| managerId   | int     |
+-------------+---------+
```

**示例 1**：

```text
输入：
Employee 表:
+----+-------+--------+-----------+
| id | name  | salary | managerId |
+----+-------+--------+-----------+
| 1  | Joe   | 70000  | 3         |
| 2  | Henry | 80000  | 4         |
| 3  | Sam   | 60000  | Null      |
| 4  | Max   | 90000  | Null      |
+----+-------+--------+-----------+
输出：
+----------+
| Employee |
+----------+
| Joe      |
+----------+
```

**提示**：

- 同表自连接：员工行与其经理行关联后比较薪水。

## 💻 解题思路

### 思路1：自连接（LEFT JOIN + WHERE）

#### 核心逻辑

Employee 与自身按 `e1.managerId = e2.id` 连接，`WHERE e1.salary > e2.salary` 过滤出比经理挣得多的员工。用 LEFT JOIN 可兼容（实际本数据 managerId 均非空，INNER JOIN 亦可）。

#### 代码实现

```sql
select e1.name as Employee
from employee e1
left join employee e2
on e1.managerId = e2.id
where e1.salary > e2.salary
```

#### 📊 性能分析

- 时间复杂度：$O(n)$（managerId 有索引时）
- 空间复杂度：$O(n)$

#### 思考

- 等价写法：相关子查询 `WHERE salary > (SELECT salary FROM Employee WHERE id = e1.managerId)`。

## 📝 总结

同一张表里比较行与行 → 自连接；比较对象由外键（managerId）给出。
