# 176. 第二高的薪水

> **难度**：中等 | **题号**：176 | **链接**：[176. 第二高的薪水 - 力扣（LeetCode）](https://leetcode.cn/problems/second-highest-salary/description/)

## 🎯 问题描述

**描述**：查询 Employee 表中第二高的不同薪水。如果没有第二高的薪水，返回 `null`。

**表：Employee**

```text
+-------------+------+
| 列名         | 类型 |
+-------------+------+
| id          | int  |
| salary      | int  |
+-------------+------+
```

**示例 1**：

```text
输入：
Employee 表:
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+
输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| 200                 |
+---------------------+
```

**示例 2**：

```text
输入：
Employee 表:
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+
输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| null                |
+---------------------+
```

**提示**：

- 需要 DISTINCT 去重（并列最高不能算两个）。
- 无结果时要输出 `null` 而不是空表 → 用标量子查询。

## 💻 解题思路

### 思路1：LIMIT 偏移取第二名

#### 核心逻辑

`ORDER BY salary DESC LIMIT 1,1` 跳过第一名取第二个；先 `DISTINCT` 去重。关键点：`SELECT` 里直接 `LIMIT` 找不到行时返回**空表**，套一层标量子查询后，无行时才返回 `NULL`。

#### 代码实现

```sql
select (select distinct salary

        from Employee

        order by salary desc

        limit 1,1

        ) as SecondHighestSalary
```

#### 📊 性能分析

- 时间复杂度：$O(n \log n)$，排序取第 2 行
- 空间复杂度：$O(n)$

#### 思考

- 通用化写法见 第N高的薪水（用函数 + `LIMIT M,1`）。

## 📝 总结

「第 K 高」三件套：DISTINCT 去重 + ORDER BY DESC + LIMIT k-1,1；标量子查询兜底返回 NULL。
