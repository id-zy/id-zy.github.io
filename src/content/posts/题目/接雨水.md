# 接雨水

> **难度**：困难 | **题号**：42 | **链接**：https://leetcode.cn/problems/trapping-rain-water/ | **数据结构**：双指针 / 数组 / 单调栈

## 🎯 问题描述

**描述**：
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1**：

```text
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，
     在这种情况下，可以接 6 个单位的雨水。
```

**示例 2**：

```text
输入：height = [4,2,0,3,2,5]
输出：9
```

**提示**：
- `n == height.length`
- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

## 💻 解题思路

### 思路 1：双指针（对称收缩，$O(1)$ 空间）

#### 核心逻辑

**单个柱子能接的水 = `min(左边最高, 右边最高) - 自身高度`**（结果为负数则取 0）。

朴素做法要预处理出每个位置的「左/右最大高度」两个数组（$O(n)$ 空间）。双指针把它压到 $O(1)$：

- `pre_max`：`height[0..left]` 的最大值；`suf_max`：`height[right..n-1]` 的最大值。
- 当 `pre_max < suf_max` 时，`left` 位置的水量由 `pre_max` **唯一确定**——因为右侧存在 `suf_max` 这个不低于 `pre_max` 的柱子兜底，短板一定在左边。故 `ans += pre_max - height[left]`，然后 `left++`。
- 否则对称处理 `right` 端：`ans += suf_max - height[right]`，`right--`。
- 每步都「搞定」掉一个位置，问题规模缩小，直到两指针相遇。

#### 代码实现

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        ans = pre_max = suf_max = 0
        left, right = 0, len(height) - 1
        while left < right:
            pre_max = max(pre_max, height[left])    # 前缀最大值
            suf_max = max(suf_max, height[right])   # 后缀最大值
            if pre_max < suf_max:                   # left 处的接水量已确定
                ans += pre_max - height[left]
                left += 1                           # 问题缩小到 [left+1, right]
            else:                                   # right 处的接水量已确定
                ans += suf_max - height[right]
                right -= 1                          # 问题缩小到 [left, right-1]
        return ans
```

#### 📊 性能分析

- 时间复杂度：$O(n)$ —— 每个位置至多被处理一次。
- 空间复杂度：$O(1)$ —— 只用了常数个变量（优于 DP 的 $O(n)$）。

#### 思考

1. **为什么 `pre_max < suf_max` 就能确定 `left` 的水量？** 右边已经出现了 `suf_max` 这根不低于 `pre_max` 的柱子，说明「右侧最高」不会成为短板，`left` 的接水上限由左侧的 `pre_max` 决定。短板一旦确定，水量即可结算。
2. **为什么 `while left < right` 不用管相遇点？** 两指针相遇时，该位置必然是某一侧的最大值，`min(...) - height == 0`，贡献为 0，可以不算。
3. **三种解法对比**：
   - **前缀/后缀最大数组（DP）**：最好理解，$O(n)$ 时间 / $O(n)$ 空间；
   - **双指针**：本题写法，$O(n)$ 时间 / $O(1)$ 空间，面试首选；
   - **单调栈**：按「凹槽」横向累加，$O(n)$ 时间，但需要栈空间、思路更绕。
4. **与 盛最多水的容器 的区别**：都用双指针，但那题求「选两根柱子围成的**最大面积**」（只有一个容器），本题求「整个地形能接的**雨水总量**」。

## 📝 总结

**经典的「困难难度、双指针」题。** 核心是把「每个位置的接水量 = min(左最高, 右最高) - 自身高度」这个公式，用左右两个 `max` 变量 + 双指针在 $O(1)$ 空间里在线推导出来。记住那句判断题：**哪边的「当前最高」更矮，就先结算哪边的柱子**。
