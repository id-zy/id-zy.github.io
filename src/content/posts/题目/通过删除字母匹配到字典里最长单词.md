# 524. 通过删除字母匹配到字典里最长单词

## 🎯 问题描述
**描述**：  
给定一个字符串 `s` 和一个字符串数组 `dictionary`，找到 `dictionary` 中最长的字符串，该字符串可以通过删除 `s` 中的一些字符得到。  
如果答案不止一个，返回长度最长且字典序最小的字符串。如果不存在，返回空字符串。

**说明**：  
- 子序列的定义：在不改变字符相对顺序的情况下，从原字符串中删除若干字符后得到的新字符串。
- 答案要求：首先按长度降序，若长度相同则按字典序升序。

**示例**：

- 示例 1：

```text
输入: s = "abpcplea", dictionary = ["ale","apple","monkey","plea"]
输出: "apple"
解释: 可匹配的单词有 "ale"（长度3）、"apple"（长度5）、"plea"（长度4），最长的为 "apple"。
```

- 示例 2：

```text
输入: s = "abpcplea", dictionary = ["a","b","c"]
输出: "a"
```

## 💻 解题思路
### 思路：排序 + 双指针（贪心匹配）
#### 算法步骤
1. 对 `dictionary` 进行排序：先按长度降序（`-len(x)`），长度相同则按字典序升序（`x`）。
2. 遍历排序后的 `dictionary` 中的每个单词 `word`：
   - 使用双指针（或单指针）检查 `word` 是否为 `s` 的子序列：
     - 指针 `i` 指向 `word` 的起始位置。
     - 遍历 `s` 中的每个字符 `ch`，如果 `i < len(word)` 且 `word[i] == ch`，则 `i += 1`。
     - 如果最终 `i == len(word)`，说明 `word` 是 `s` 的子序列，直接返回该单词。
3. 如果遍历完所有单词都没有匹配，返回空字符串 `""`。

#### 代码实现
```python
from typing import List

class Solution:
    def findLongestWord(self, s: str, dictionary: List[str]) -> str:
        dictionary.sort(key=lambda x: (-len(x), x))
        for word in dictionary:
            i = 0
            for ch in s:
                if i < len(word) and word[i] == ch:
                    i += 1
            if i == len(word):
                return word
        return ""
```

#### 📊 性能分析
- 时间复杂度：$O(d \times (len(s) + len(word)))$，其中 $d$ 是字典中单词的个数，最坏情况需要检查每个单词是否为子序列。但由于排序后的字典通常很快能返回结果，实际运行较快。
- 空间复杂度：$O(1)$（忽略排序的栈空间）。

#### 思考
该解法利用排序将候选单词按优先级排列，然后使用双指针贪心检查子序列。由于题目要求的是“最长且字典序最小”，排序后第一个匹配的单词即为答案。检查子序列的双指针方法效率高（$O(len(s))$），整体解法简洁且直接。如果字典很大，可以进一步优化（如预处理 `s` 的下一个字符位置），但本题数据规模通常较小，当前解法已足够。
