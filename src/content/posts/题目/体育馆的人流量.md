# 体育馆的人流量

> **难度**：困难 | **题号**：601 | **链接**：[601. 体育馆的人流量](https://leetcode.cn/problems/human-traffic-of-stadium/) | **数据结构**：sql

## 🎯 问题描述

**描述**：

`Stadium` 表：

```text
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| visit_date    | date    |
| people        | int     |
+---------------+---------+
```

`visit_date` 是主键，每日人流量信息按日期升序记录。请找出**每行**人数都不少于 100 的**连续**（至少三行）记录，返回按 `visit_date` 升序排列的结果。

**示例 1**：

```text
输入：
Stadium 表：
+------+------------+-----------+
| id   | visit_date | people    |
+------+------------+-----------+
| 1    | 2017-01-01 | 10        |
| 2    | 2017-01-02 | 109       |
| 3    | 2017-01-03 | 150       |
| 4    | 2017-01-04 | 99        |
| 5    | 2017-01-05 | 145       |
| 6    | 2017-01-06 | 1455      |
| 7    | 2017-01-07 | 199       |
| 8    | 2017-01-09 | 188       |
+------+------------+-----------+
输出：
+------+------------+-----------+
| id   | visit_date | people    |
+------+------------+-----------+
| 5    | 2017-01-05 | 145       |
| 6    | 2017-01-06 | 1455      |
| 7    | 2017-01-07 | 199       |
| 8    | 2017-01-09 | 188       |
+------+------------+-----------+
```

**提示**：
- id 虽然基本连续，但**可能断号**（如示例中缺 id=8 对应的 2017-01-08）——但只要日期/编号相邻仍算连续段，所以按「过滤后的 id 顺序」判定连续，而非绝对 id 差。
- 至少三行，三行及以上都要返回。

## 💻 解题思路

### 思路 1：差值分组法（Gaps & Islands，我的解法）

#### 核心逻辑

- 先过滤 `people >= 100`，再对剩余记录按 id 排序生成行号 `rn`；
- **连续记录的 `id - rn` 恒为定值**（id 每步 +1，rn 也每步 +1），用这个差值 `grp` 把连续段归为一组；
- 按 `grp` 分组，`HAVING COUNT(*) >= 3` 筛出长度 ≥ 3 的组，再取回这些组的全部行。

#### 代码实现

```sql
WITH FilteredStadium AS (
    SELECT
        id,
        visit_date,
        people,
        -- 先过滤，再对剩余记录按 id 排序生成 rn
        id - ROW_NUMBER() OVER (ORDER BY id) AS grp
    FROM Stadium
    WHERE people >= 100
),
ValidGroups AS (
    SELECT grp
    FROM FilteredStadium
    GROUP BY grp
    HAVING COUNT(*) >= 3
)
SELECT id, visit_date, people
FROM FilteredStadium
WHERE grp IN (SELECT grp FROM ValidGroups)
ORDER BY visit_date;
```

#### 📊 性能分析

- 时间复杂度：$O(n \log n)$（窗口函数排序）
- 空间复杂度：$O(n)$

#### 思考

- **为什么先过滤再编号**：`id - ROW_NUMBER()` 的「定值 ⇒ 连续」成立的前提是编号序列紧跟着 id 逐 1 递增。先 `WHERE people >= 100` 过滤掉低人流行，剩下的行若 id 仍逐 1 递增，`id - rn` 就不变——这恰好把「人流连续 ≥ 100」的段归成一组。
- 对照解法是三表自连接（`s1.id = s2.id - 1 AND s1.id = s3.id - 2 ...`）判断「连续三天」，但要分别覆盖连续 3/4/5…天，写起来繁琐且难扩展；差值分组法对任意长度连续段一次搞定，是本题标为「困难」时最值得掌握的模式。
- 同款模式：连续出现的数字（180，找至少连续出现三次的数字），可以对照复习。

## 📝 总结

「连续 N 行满足条件」= **Gaps & Islands** 差值分组：过滤 → `id - ROW_NUMBER()` 分段 → `HAVING COUNT(*)` 验长度。记住先过滤再编号这一步顺序不能反。
