# 字母异位词分组

> **难度**：中等 | **题号**：49 | **链接**：https://leetcode.cn/problems/group-anagrams/ | **数据结构**：哈希表 / 字符串 / 排序

## 🎯 问题描述

**描述**：
给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。
字母异位词 是由重新排列源单词的所有字母得到的一个新单词。

**示例 1**：

```text
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2**：

```text
输入：strs = [""]
输出：[[""]]
```

**示例 3**：

```text
输入：strs = ["a"]
输出：[["a"]]
```

**提示**：
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 💻 解题思路

### 思路 1：排序作为分组 key

#### 核心逻辑

互为字母异位词的两个字符串，**排序后一定完全相同**（如 `eat` / `tea` / `ate` 排序后都是 `aet`）。
于是把「排序后的字符串」当作哈希表的 **key**，原字符串分到同一个桶里即可：

- key 相同 → 属于同一组 → 追加进 `h[key]` 这个 list。
- 遍历结束后，`h` 的所有 value 就是答案。

#### 代码实现

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        h = {}
        for ch in strs:
            key = "".join(sorted(ch))       # 排序后的字符串作为分组标识
            if key not in h:
                h[key] = []
            h[key].append(ch)
        return list(h.values())
```

#### 📊 性能分析

- 时间复杂度：$O(n \cdot k \log k)$ —— $n$ 个字符串，每个长度 $k$，排序一次 $O(k \log k)$。
- 空间复杂度：$O(n \cdot k)$ —— 哈希表与结果需要存下所有字符。

> 进阶（$O(nk)$）：不排序，改用 **26 位字符计数元组** 作为 key（`tuple(count[c] for c in 'abcdefghijklmnopqrstuvwxyz')`）。计数法省掉排序的 $\log k$，但常数稍大；面试里作为加分项提一句即可。

#### 思考

1. **key 必须可哈希**：字符串、`tuple` 都可以当 key，`list` 不行。排序后用 `"".join(...)` 得到字符串最方便。
2. **`h[key].append(ch)` 的惯用写法**：先判断 key 是否存在、不存在就初始化为空 list。用 `defaultdict(list)` 可以一行写完。
3. **dict 保留插入顺序**（Python 3.7+），所以返回结果稳定；但本题允许任意顺序，无需刻意处理。
4. **空串**：`""` 排序后仍是 `""` → 自成一桶，示例 2 正确返回 `[[""]]`。

## 📝 总结

**「把等价关系映射成一个可哈希的 key」是分组类问题的通用套路。** 异位词的等价类不变量就是「排序后的字符串」（或「字符计数」）。抓住不变量 → 哈希表一键分组。下一步可看 找到字符串中所有字母异位词，把「分组」升级为「在长串里滑窗寻找定长异位词」。
