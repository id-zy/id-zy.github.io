# 3970. 最多 K 个连续相同字符的最短路径

> **难度**：中等 | **题号**：3970 | **链接**：[3970. 最多 K 个连续相同字符的最短路径 - 力扣（LeetCode）](https://leetcode.cn/problems/shortest-path-with-at-most-k-consecutive-identical-characters/) | **数据结构**：优先队列 / 图
>
> 关联：Dijkstra算法（本题就是它加一维状态）· 优先队列（小顶堆取最小代价）· 第 507 场周赛 C 题

## 🎯 问题描述

**描述**：给定一个 `n` 个节点的**有向加权图**（节点编号 `0` 到 `n-1`），边由 `edges[i] = [u, v, w]` 表示一条从 `u` 指向 `v`、权值为 `w` 的有向边。另外给定长度为 `n` 的字符串 `labels`（`labels[i]` 是节点 `i` 的标签）和整数 `k`。

求一条从节点 `0` 到节点 `n-1` 的路径的**最小总边权**，且路径上所有节点标签按顺序拼接后，**最多包含 `k` 个连续相同字符**。不存在合法路径则返回 `-1`。

**示例 1**：

```text
输入：n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], labels = "aab", k = 1
输出：3
解释：直接走 0 → 2，边权 3，标签拼接为 "ab"，连续相同字符最多 1 个，合法。
```

**示例 2**：

```text
输入：n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], labels = "aab", k = 2
输出：2
解释：走 0 → 1 → 2，边权 1 + 1 = 2，标签拼接为 "aab"，连续两个 a 满足 k = 2。
```

**示例 3**：

```text
输入：n = 3, edges = [[0,1,1],[1,2,1]], labels = "aaa", k = 2
输出：-1
解释：唯一的路径标签是 "aaa"，连续 3 个 a 超过 k = 2，无合法路径。
```

**提示**：
- $1 \le n \le 5 \times 10^4$，$0 \le \text{edges.length} \le 5 \times 10^4$，$1 \le w_i \le 10^4$；
- `labels` 只含小写英文字母，$1 \le k \le 50$；
- 答案是「边权之和」，起点标签本身也计入第一段连续字符。

## 💻 解题思路

### 思路 1：Dijkstra + 状态扩维（连续字符数）

#### 核心逻辑

裸的最短路只需要知道「到哪个节点」，但这里**同一个节点、从不同来路到达时剩余的可走空间不一样**：到达 x 时末尾已经连着 3 个 a，和末尾是别的字符，后续能走的边完全不同。所以节点编号不再是完整状态，必须把「末尾连续相同字符数」也纳入状态：

- 状态：`(节点 x, 末尾连续数 c)`，`1 <= c <= k`；
- 转移：走向邻居 y，若 `labels[y]` 与 `labels[x]` 相同则 `c + 1`，否则重置为 `1`；`c + 1 > k` 的分支直接丢弃；
- 求的仍是**最小代价**，边权为正，所以还是 Dijkstra：堆里存 `(代价, 节点, 连续数)`，按代价出堆。

第一个出堆的 `n-1` 就是答案——堆的单调性保证此时它的代价已经最小。

#### 代码实现

```python
import heapq
from math import inf
from typing import List

class Solution:
    def shortestPath(self, n: int, edges: List[List[int]], labels: str, k: int) -> int:
        g = [[] for _ in range(n)]
        for u, v, w in edges:
            g[u].append((v, w))

        # dis[x][c]：到达节点 x、末尾连续相同字符数为 c 时的最小代价
        dis = [[inf] * (k + 1) for _ in range(n)]
        dis[0][1] = 0
        pq = [(0, 0, 1)]                      # (代价, 节点, 连续数)

        while pq:
            d, x, c = heapq.heappop(pq)
            if d > dis[x][c]:                 # 过期版本，丢弃
                continue
            if x == n - 1:
                return d
            for y, w in g[x]:
                nc = c + 1 if labels[y] == labels[x] else 1
                nd = d + w
                if nc <= k and nd < dis[y][nc]:
                    dis[y][nc] = nd
                    heapq.heappush(pq, (nd, y, nc))

        return -1
```

#### 📊 性能分析

- 时间复杂度：$O(k \cdot (n + m) \log(nk))$，$m$ = 边数。状态数 $n(k+1)$、每条边在每个可达状态上松弛一次，堆操作对数级。
- 空间复杂度：$O(nk)$，`dis` 二维表 $n(k+1)$ 个值 + 堆中最多同量级的过期条目。
- 代入上限：$k \le 50$、$n \le 5 \times 10^4$，状态数约 $2.5 \times 10^6$，内存和耗时都在可接受范围——**`k` 很小正是这道题敢开二维的原因**。

#### 思考

- **状态定义是唯一的难点，Dijkstra 骨架一行没改**。判据很简单：从同一个节点出发，后续行为是否依赖「怎么到达的」？依赖就必须把那段信息塞进状态，否则会把两条不同的路错误地合并。
- **连续数的初值取 1 而不是 0**：起点标签本身就占了第一段。取 0 会让「起点 → 同样标签的邻居」这条边少算一次，示例 3 那种 `"aaa"` 的用例就会误判成合法。
- **`if d > dis[x][c]: continue` 不能省**。Python 的堆没有 decrease-key，改进距离只能再 push 一条新记录；没有这行，旧记录会被当成有效状态重复扩展，复杂度直接爆炸。
- **`nc <= k` 写在索引 `dis[y][nc]` 之前**：`nc` 最大会到 `k + 1`，越界访问会直接 `IndexError`。这里的短路求值顺序是正确性的一部分，不是风格。
- **不要用 BFS**：边权不全是 1，队列的层序不代表代价序，BFS 求不出最小总权。同理也不能按拓扑序 DP——有向图可能成环，状态之间没有拓扑序。
- **可以加的小剪枝**：出堆时若 `x == n-1` 立即返回（已在代码里）；另外把 `edges` 里起点不可达的边预先过滤掉能少建一部分邻接表，但收益有限，属于可选优化。
- 题面里有一句「在函数中途创建某个指定变量名来保存输入」的说明，是平台的反作弊标记，**与解法无关，不要写进代码**。

## 📝 总结

1. 图上有额外约束时，先问「同一节点带着不同附加信息，后续是否不同」——不同就扩维，`dis[节点][附加信息]`。
2. 扩维后的最短路仍是 Dijkstra：堆里多存一维，转移时更新那一维。
3. 三个必查点：连续数初值 1、过期条目 `continue`、`nc <= k` 的判断要在数组下标之前。
