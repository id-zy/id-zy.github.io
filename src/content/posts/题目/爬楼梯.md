# 70. 爬楼梯 - Climbing Stairs

## 🎯 问题描述
**描述**：  
假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。  
每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶？  
注意：给定 `n` 是一个正整数。

**示例**：

- 示例 1：

```text
输入: n = 2
输出: 2
解释: 1 阶 + 1 阶，2 阶
```

- 示例 2：

```text
输入: n = 3
输出: 3
解释: 1+1+1, 1+2, 2+1
```

## 💻 解题思路
### 思路一：动态规划（迭代）
#### 算法步骤
1. 定义 `dp[i]` 表示爬到第 `i` 阶楼梯的方法数。
2. 初始条件：`dp[1] = 1`，`dp[2] = 2`（n≥1）。
3. 转移方程：`dp[i] = dp[i-1] + dp[i-2]`（因为最后一步可以跨1阶或2阶）。
4. 遍历 `i` 从 3 到 `n`，计算 `dp[i]`。
5. 返回 `dp[n]`。

#### 代码实现
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        a, b = 1, 2
        for _ in range(3, n+1):
            a, b = b, a + b
        return b
```

#### 📊 性能分析
- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

---

### 思路二：递归 + 记忆化搜索（DFS + @cache）
#### 算法步骤
1. 定义递归函数 `dfs(i)` 表示爬到第 `i` 阶的方法数。
2. 递归基：`dfs(1)=1`，`dfs(2)=2`。
3. 递归关系：`dfs(i) = dfs(i-1) + dfs(i-2)`。
4. 使用 `@cache` 装饰器缓存计算结果，避免重复计算。
5. 返回 `dfs(n)`。

#### 思路二：代码实现（用户提供）
```python
from functools import cache

class Solution:
    def climbStairs(self, n: int) -> int:
        @cache
        def dfs(i):
            if i <= 2:
                return i
            return dfs(i-1) + dfs(i-2)
        return dfs(n)
```

#### 📊 性能分析
- 时间复杂度：$O(n)$，每个状态计算一次。
- 空间复杂度：$O(n)$，递归栈深度和缓存空间。

#### 思考
两种解法本质相同，都利用了斐波那契数列的递推关系。动态规划迭代法空间更优，而记忆化递归更直观，适合理解问题的递归结构。对于 `n` 较大时（如 `n=45`），两种方法都能快速得出结果。推荐在面试中使用迭代法以节省空间，但记忆化递归在代码可读性上更胜一筹。
