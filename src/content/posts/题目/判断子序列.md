# 392. 判断子序列

## 🎯 问题描述
**描述**：  
给定字符串 `s` 和 `t`，判断 `s` 是否为 `t` 的子序列。  
子序列是指：在不改变字符相对顺序的情况下，从 `t` 中删除一些字符（也可以不删除）后得到 `s`。

**说明**：  
- 空字符串是任何字符串的子序列。
- `s` 和 `t` 的长度都不超过 10^4。

**示例**：

- 示例 1：

```text
输入: s = "abc", t = "ahbgdc"
输出: true
解释: s 中的字符按顺序出现在 t 中：a(0), b(3), c(4)。
```

- 示例 2：

```text
输入: s = "axc", t = "ahbgdc"
输出: false
```

## 💻 解题思路
### 思路：双指针（贪心匹配）
#### 算法步骤
1. 初始化指针 `i = 0`，指向 `s` 的起始位置，`n = len(s)`。
2. **关键**：若 `s == t`，直接返回 `True`。  
   - 这能正确处理 `s` 和 `t` 完全相等的情况，**特别包括两者都为空字符串**（`"" == ""`）。  
   - 如果没有该判断，当 `s == ""` 且 `t == ""` 时，`for` 循环不会执行，最终返回 `False`，与预期（`True`）不符。
3. 遍历 `t` 中的每个字符 `ch`：
   - 如果 `i < n` 且 `s[i] == ch`，则 `i += 1`（成功匹配一个字符）。
   - 如果 `i == n`，说明所有字符都已匹配，提前返回 `True`。
4. 遍历结束后，若 `i == n` 则返回 `True`，否则返回 `False`。

#### 代码实现
```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        i, n = 0, len(s)
        if s == t:
            return True
        for ch in t:
            if i < n and s[i] == ch:
                i += 1
            if i == n:
                return True
        return False
```

#### 📊 性能分析
- 时间复杂度：$O(len(t))$，但 `s == t` 的比较在最坏情况下需要 $O(len(s))$ 时间，整体仍为线性。
- 空间复杂度：$O(1)$，仅使用常数个变量。

#### 思考
双指针贪心匹配是判断子序列的标准解法。该实现中的 `if s == t: return True` 必不可少，它确保了 `s == t` 时直接返回正确结果，尤其是处理空字符串时，避免了因循环体不执行而错误返回 `False` 的问题。如果去掉该判断，则需要在循环前额外处理 `if not s: return True`，但当前写法已经简洁地一并覆盖了这两种边界情况。
