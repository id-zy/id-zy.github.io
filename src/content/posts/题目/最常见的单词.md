# 最常见的单词

> **难度**：简单 | **题号**：[819. Most Common Word](https://leetcode.cn/problems/most-common-word/) | **数据结构**：哈希表 / 字符串

## 🎯 问题描述

**描述**：

给定一个段落 `paragraph` 和一个禁用单词列表 `banned`，返回**出现次数最多、且不在禁用列表中的单词**。

- 题目保证**至少有一个**单词不在禁用列表中，且答案是**唯一**的；
- 单词**不区分大小写**，答案返回**小写**；
- 段落中的标点符号不计入单词（`"ball,"` 里的 `"ball"` 算一个词）。

**示例 1**：

```text
输入：paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]
输出："ball"
解释："hit" 出现 3 次但被禁用；"ball" 出现 2 次（含 "BALL"），是出现最多的非禁用词。
```

**示例 2**：

```text
输入：paragraph = "a.", banned = []
输出："a"
```

**提示**：
- `1 <= paragraph.length <= 1000`，只含字母、空格和 `!?',;.`
- `0 <= banned.length <= 100`
- `banned` 中的单词均为小写且互不相同

## 💻 解题思路

### 思路 1：小写化 + 正则切分 + Stream 分组计数

#### 核心逻辑

1. `paragraph.toLowerCase()` 统一大小写——**必须在切分之前**，否则 `"BALL"` 和 `"ball"` 会被算成两个词；
2. `split("[^a-z]+")` **以"非字母的连续片段"为分隔符**切词，顺带把标点和空格一起吃掉；
3. `banned` 转成 `HashSet`，过滤时是 $O(1)$ 查找；
4. `groupingBy(Function.identity(), counting())` 得到 `单词 → 次数`；
5. `max(comparingByValue())` 取次数最大的那个条目，`map(getKey)` 取出单词。

#### 代码实现

```java
class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        Set<String> bannedSet = new HashSet<>(Arrays.asList(banned));

        return Arrays.stream(paragraph.toLowerCase().split("[^a-z]+"))
                .filter(w -> !w.isEmpty() && !bannedSet.contains(w))  // ① 过滤空串
                .collect(Collectors.groupingBy(
                        Function.identity(),
                        Collectors.counting()))
                .entrySet()
                .stream()
                .max(Map.Entry.comparingByValue())
                .map(Map.Entry::getKey)
                .orElse("");
    }
}
```

不用 Stream 的等价写法（更好控制，也更快）：

```java
class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        Set<String> bannedSet = new HashSet<>(Arrays.asList(banned));
        Map<String, Integer> freq = new HashMap<>();

        String best = "";
        int bestCount = 0;

        for (String w : paragraph.toLowerCase().split("[^a-z]+")) {
            if (w.isEmpty() || bannedSet.contains(w)) continue;
            int c = freq.merge(w, 1, Integer::sum);
            if (c > bestCount) {          // 严格大于：天然满足"答案唯一"
                bestCount = c;
                best = w;
            }
        }
        return best;
    }
}
```

#### 📊 性能分析

- 时间复杂度：$O(n + m)$，$n$ 为段落长度（切分 + 遍历），$m$ 为禁用词个数（建 `HashSet`）。Stream 版多一次分组与 `max`，同阶。
- 空间复杂度：$O(n + m)$，词频表与禁用集合。

#### 思考

- **原稿最大的隐患：`split("[^a-z]+")` 在开头有标点时会产生一个空串。** 例如 `paragraph = "a."` 没问题（`["a"]`），但 `paragraph = ".a"` 会切出 `["", "a"]`——空串不在 `banned` 里，会被当成一个"出现 1 次的单词"参与比较。如果另一个词也只出现 1 次，`max` 在平局时的取舍依 `HashMap` 迭代顺序而定，**可能返回 `""`**。所以 `filter` 里必须加 `!w.isEmpty()`。
- **`split` 与 `replaceAll` 的区别很关键**：`replaceAll("[^a-z]", "")` 会把 `"a.b"` 压成 `"ab"`（两个词粘连）；`replaceAll("[^a-z]", " ")` + 再 `split("\\s+")` 或用 `split("[^a-z]+")` 才是正确切分。**"删除标点"和"把标点当分隔符"是两件不同的事。**
- 正则里 `+` 不能省：`split("[^a-z]")` 遇到 `", "`（逗号+空格）会切出多余空串；`[^a-z]+` 把连续的非字母片段当成一个分隔符，才干净。
- **平局处理**：题目保证答案唯一，所以 `max` 的平局规则不影响正确性；但工程代码里"取第一个最大"和"取最后一个最大"结果不同，Stream 的 `max` 在相等时保留**先遇到的**，依赖 `HashMap` 迭代顺序 = 不可控。自写循环用 `c > bestCount`（严格大于）就明确表达"平局保留先出现的"。
- 用 `int` 手写比 `Map.Entry<String, Long>` 少一层装箱：`counting()` 返回 `Long`，`comparingByValue()` 比的是 `Long`，小规模无所谓，但**数据量大时装箱开销是真的**。

## 📝 总结

1. 顺序不能变：**先 `toLowerCase`，再切分，再过滤禁用词**。
2. `split("[^a-z]+")` 是"把标点当分隔符"，不是"删除标点"；开头/结尾有标点时会产出空串，**必须 `filter(!isEmpty)`**。
3. 禁用词放 `HashSet`，过滤 $O(1)$。
4. 答案唯一时 `max` 可用；不唯一时要显式定义平局规则。
