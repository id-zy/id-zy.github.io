# 183. 从不订购的用户

> **难度**：简单 | **题号**：183 | **链接**：[183. 从不订购的客户 - 力扣（LeetCode）](https://leetcode.cn/problems/customers-who-never-order/)

## 🎯 问题描述

**描述**：找出所有**从不订购任何东西**的客户，返回客户姓名。

**表：Customers / Orders**

```text
Customers 表:
+----+-------+
| id | name  |
+----+-------+
Orders 表:
+----+------------+
| id | customerId |
+----+------------+
```

**示例 1**：

```text
输入：
Customers 表:
+----+-------+
| id | name  |
+----+-------+
| 1  | Joe   |
| 2  | Henry |
| 3  | Sam   |
| 4  | Max   |
+----+-------+
Orders 表:
+----+------------+
| id | customerId |
+----+------------+
| 1  | 3          |
| 2  | 1          |
+----+------------+
输出：
+-----------+
| Customers |
+-----------+
| Henry     |
| Max       |
+-----------+
```

**提示**：

- "不存在于 Orders 中" → LEFT JOIN 补 NULL 后过滤，或 NOT EXISTS。

## 💻 解题思路

### 思路1：LEFT JOIN + IS NULL（反连接）

#### 核心逻辑

Customers LEFT JOIN Orders，从未订购的客户 Orders 侧为 NULL，`WHERE o.Id IS NULL` 过滤出反集。这就是「反连接（anti-join）」模式。

#### 代码实现

```sql
select name as Customers
from Customers c
left join Orders o
on c.id = o.customerId
where o.Id is Null
```

#### 📊 性能分析

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

#### 思考

- NOT IN 写法有 NULL 陷阱（见 SQL-子查询），推荐 `NOT EXISTS` 或本写法。

## 📝 总结

找"没有发生过 X 的主体"：LEFT JOIN + IS NULL 或 NOT EXISTS，二者都无 NULL 陷阱。
