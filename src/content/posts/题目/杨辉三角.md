# 杨辉三角

## 🎯 问题描述
给定一个非负整数 _`numRows`，_生成「杨辉三角」的前 _`numRows`_ 行。
在**杨辉三角**中，每个数是它左上方和右上方的数的和。
## 💻 代码实现
```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        n=numRows
        L = [] 
        for i in range(n):
            line=[]
            for j in range(i+1):
                if j==0 or i==j:
                    line.append(1)
                else :
                    a=L[i-1][j-1]+L[i-1][j]
                    line.append(a)
            L.append(line)
        return L
```
