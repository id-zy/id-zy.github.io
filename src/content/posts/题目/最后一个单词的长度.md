# 最后一个单词的长度

> **难度**：简单 | **题号**：58 | **链接**：[58. 最后一个单词的长度](https://leetcode.cn/problems/length-of-last-word/) | **数据结构**：字符串

## 🎯 问题描述

**描述**：

给你一个字符串 `s`，由若干单词组成，单词前后用**一些空格字符**隔开。返回字符串中**最后一个单词**的长度。

**单词**是指仅由字母组成、不包含任何空格字符的最大子字符串。

**示例 1**：

```text
输入：s = "Hello World"
输出：5
解释：最后一个单词是 "World"，长度为 5。
```

**示例 2**：

```text
输入：s = "   fly me   to   the moon  "
输出：4
解释：最后一个单词是 "moon"，长度为 4。注意首尾与中间都可能有多个空格。
```

**提示**：
- `1 <= s.length <= 10^4`
- `s` 仅有英文字母和空格 `' '` 组成
- `s` 中至少存在一个单词
- **陷阱**：末尾可能有任意多个空格——最后一个「非空 token」才是单词。

## 💻 解题思路

### 思路 1：split 后取最后一个元素

#### 核心逻辑

1. Python：`s.split()` **不带参数**调用时会按「任意连续空白」切分，并**自动丢弃空串**，所以切出来的数组天然不含空 token，直接 `len(mp[-1])` 即可；
2. Java：`split("\\s+")` 保留语义上的空 token 处理，因此先 `trim()` 去掉首尾空白（否则末尾空格会在结果尾部产生一个 `""`），再按 `\s+` 切分，取 `ch[ch.length - 1]` 的长度。

#### 代码实现

```python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        mp = s.split()
        return len(mp[-1])
```

```java
class Solution {
    public int lengthOfLastWord(String s) {
        String[] ch = s.trim().split("\\s+");
        return ch[ch.length - 1].length();
    }
}
```

#### 📊 性能分析

- 时间复杂度：$O(n)$，$n$ 为字符串长度——`split` 需扫全串。
- 空间复杂度：$O(n)$，切分出的 token 数组与原串同规模。

#### 思考

**为什么数组的 `length` 没有括号，而字符串的 `length()` 有括号？**

在你的代码 `words[words.length - 1].length()` 中：

- `words` 是一个**数组**（`String[]`），所以用 `words.length`（**属性**，不带括号）。
- `words[words.length - 1]` 取出来的是一个**字符串**（`String` 对象），所以用 `.length()`（**方法**，带括号）。

这个问题已经拆成独立概念卡：Java-数组length与字符串length方法，此处只留结论——**数组是语言内置对象，`length` 是语言规范直接规定的 `public final` 字段；`String` 是普通类，`length()` 是封装内部数组的方法**。

### 思路 2：从尾部倒着扫（进阶，O(1) 空间）

`split` 会把整串切开，其实只为求「最后一个单词」大可不必：

1. 从字符串**末尾**向前跳过所有空格（处理末尾空白）；
2. 继续向前数，直到再遇到空格或到达开头，数的个数就是答案。

```python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        i = len(s) - 1
        while i >= 0 and s[i] == ' ':
            i -= 1          # 跳过末尾空格
        end = i
        while i >= 0 and s[i] != ' ':
            i -= 1          # 数最后一个单词的长度
        return end - i
```

时间仍为 $O(n)$（最坏全串一个单词），但空间降到 $O(1)$——这是本题想考察的真正解法，面试建议先给 split 版再主动给倒扫版。

## 📝 总结

一句话：**取最后一个非空 token——split 版一把梭，倒扫版省空间**。

两个最容易踩的坑都在「空格」上：Python 的 `split()` 不带参数会自动吞掉连续与首尾空白，Java 的 `split("\\s+")` 则需要手动 `trim()`，跨语言迁移时不能想当然。
