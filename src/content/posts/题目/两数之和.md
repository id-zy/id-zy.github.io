# 1. 两数之和

## 🎯 问题描述

**描述**：
给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。
你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。
你可以按任意顺序返回答案。

**说明**：
-   这是一个经典的**哈希表**应用问题。
-   核心逻辑是利用哈希表存储已遍历过的数字及其下标，从而将查找互补数（`target - num`）的时间复杂度降低到 $O(1)$。
-   通过一次遍历即可完成查找。

- **示例**：
- **示例 1**：
```text
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```
- **示例 2**：
```text
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

## 💻 解题思路
### 思路1：暴力枚举

#### 思路分析

通过两层循环遍历所有可能的数字组合，检查它们的和是否等于目标值。
#### 代码实现
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]
```
#### 复杂度分析

- **时间复杂度**：O(n²) - 需要两层循环遍历所有组合
    
- **空间复杂度**：O(1) - 只使用了常数级别的额外空间
### 思路2：哈希表（一次遍历）

#### 代码实现

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # 哈希表，键为数值，值为对应的下标
        idx = {}
        
        # 遍历数组，j 为当前下标，num 为当前数值
        for j, num in enumerate(nums):
            # 计算需要的互补数
            complement = target - num
            
            # 如果互补数已经在哈希表中，说明找到了答案
            if complement in idx:
                # 返回互补数的下标和当前下标
                return [idx[complement], j]
            
            # 将当前数值和下标存入哈希表
            idx[num] = j
```

#### 📊 性能分析

- **时间复杂度**：$O(N)$
  -   其中 $N$ 是数组 `nums` 的长度。
  -   我们只遍历数组一次，每次在哈希表中查找和插入操作的平均时间复杂度都是 $O(1)$。
  -   总时间复杂度为 $O(N)$。
- **空间复杂度**：$O(N)$
  -   哈希表 `idx` 在最坏情况下需要存储 $N$ 个键值对。

#### 思考

1.  **哈希表的作用**：
    -   哈希表用于存储已经遍历过的数字及其下标。
    -   通过哈希表，我们可以快速查找是否存在一个数字，使得它与当前数字的和等于 `target`。

2.  **查找逻辑**：
    -   对于当前数字 `num`，我们需要查找的互补数是 `target - num`。
    -   如果 `target - num` 已经在哈希表中，说明我们找到了两个数字，它们的和等于 `target`。
    -   返回这两个数字的下标即可。

3.  **存储逻辑**：
    -   在查找之后，我们将当前数字 `num` 和其下标 `j` 存入哈希表。
    -   这样可以确保在后续遍历中，当前数字可以被其他数字找到。

4.  **为什么不会使用相同元素**：
    -   代码中先查找再存储。
    -   当处理 `nums[j]` 时，哈希表中只包含 `nums[0]` 到 `nums[j-1]` 的信息。
    -   因此，查找到的互补数一定来自当前元素之前的位置，不会重复使用同一个元素。

5.  **边界情况**：
    -   数组长度为 2：直接返回 `[0, 1]`。
    -   有重复元素：哈希表会存储最新的下标，但由于题目保证只有一个答案，所以不影响结果。
