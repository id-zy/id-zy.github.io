# 184. 部门工资最高的员工

> **难度**：中等 | **题号**：184 | **链接**：[184. 部门工资最高的员工 - 力扣（LeetCode）](https://leetcode.cn/problems/department-highest-salary/description/)

## 🎯 问题描述

**描述**：找出每个部门中**薪水最高**的员工（同薪并列都保留），返回部门名、员工名、薪水。

**表：Employee / Department**

```text
Employee 表:
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| name        | varchar |
| salary      | int     |
| departmentId| int     |
+-------------+---------+
Department 表:
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| name        | varchar |
+-------------+---------+
```

**示例 1**：

```text
输入：
Employee 表:
+----+-------+--------+--------------+
| id | name  | salary | departmentId |
+----+-------+--------+--------------+
| 1  | Joe   | 70000  | 1            |
| 2  | Jim   | 90000  | 1            |
| 3  | Henry | 80000  | 2            |
| 4  | Sam   | 60000  | 2            |
| 5  | Max   | 90000  | 1            |
+----+-------+--------+--------------+
输出：
+------------+----------+--------+
| Department | Employee | Salary |
+------------+----------+--------+
| IT         | Jim      | 90000  |
| Sales      | Henry    | 80000  |
| IT         | Max      | 90000  |
+------------+----------+--------+
```

**提示**：

- 每组内取最大 → 分组相关比较；并列最高都要保留，不能用 LIMIT。

## 💻 解题思路

### 思路1：相关子查询 + ALL（分组内极值）

#### 核心逻辑

先 JOIN 出部门名，再 `WHERE e.salary >= ALL(该部门所有工资)` 判断是否为组内最高。相关子查询引用外层 `e.departmentId`，逐行判断（见 SQL-子查询）。

#### 代码实现

```sql
# Write your MySQL query statement below
select d.name as "Department",e.name as "Employee",e.salary
from Employee e
join Department d
on e.departmentId = d.id
where e.salary >=
all(SELECT salary FROM Employee t WHERE e.departmentId = t.departmentId)
```

#### 📊 性能分析

- 时间复杂度：$O(n^2)$（相关子查询逐行；建议 salary+departmentId 建索引）
- 空间复杂度：$O(1)$

#### 思考

- 8.0 窗口函数写法：`RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC)` 取 rk = 1，天然支持并列，且是 部门工资前三高的所有员工 的直接简化版。
- 注意：子查询若包含 NULL 工资，`>= ALL` 会失效（UNKNOWN），实际表 salary 非空时可忽略。

## 📝 总结

分组极值两种通用解：相关子查询 `>= ALL`（5.7 可用）与 RANK 窗口取第 1 名（8.0）。
