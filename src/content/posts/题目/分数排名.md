# 178. 分数排名

> **难度**：中等 | **题号**：178 | **链接**：[178. 分数排名 - 力扣（LeetCode）](https://leetcode.cn/problems/rank-scores/)

## 🎯 问题描述

**描述**：按分数从高到低排名，分数相同的排名相同且**连续递增**（1, 2, 2, 3），返回分数和排名。

**表：Scores**

```text
+-------------+-------+
| 列名         | 类型  |
+-------------+-------+
| id          | int   |
| score       | decimal |
+-------------+-------+
```

**示例 1**：

```text
输入：
Scores 表:
+----+-------+
| id | score |
+----+-------+
| 1  | 3.50  |
| 2  | 3.65  |
| 3  | 4.00  |
| 4  | 3.85  |
| 5  | 4.00  |
| 6  | 3.65  |
+----+-------+
输出：
+-------+------+
| score | rank |
+-------+------+
| 4.00  | 1    |
| 4.00  | 1    |
| 3.85  | 2    |
| 3.65  | 3    |
| 3.65  | 3    |
| 3.50  | 4    |
+-------+------+
```

**提示**：

- 并列不跳号 → 用 `DENSE_RANK()`（跳号版是 `RANK()`，唯一版是 `ROW_NUMBER()`）。

## 💻 解题思路

### 思路1：DENSE_RANK 窗口函数

#### 核心逻辑

`DENSE_RANK() OVER (ORDER BY score DESC)`：同分并列、后续排名连续递增。需 MySQL 8.0+（本机连 3307，见 SQL-窗口函数）。

#### 代码实现

```sql
# Write your MySQL query statement below
select score,DENSE_RANK() OVER(ORDER BY score DESC) AS "rank"
from Scores
```

#### 📊 性能分析

- 时间复杂度：$O(n \log n)$
- 空间复杂度：$O(n)$

#### 思考

- 5.7 兼容写法：`COUNT(DISTINCT s2.score)` 相关子查询。

## 📝 总结

三种排名函数的差异是高频考点：ROW_NUMBER 唯一、RANK 并列跳号、DENSE_RANK 并列连续。
