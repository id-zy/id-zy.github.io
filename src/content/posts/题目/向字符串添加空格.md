# 2109. 向字符串添加空格

## 🎯 问题描述
**描述**：  
给定一个字符串 `s` 和一个整数数组 `spaces`，其中 `spaces[i]` 表示在 `s` 中第 `spaces[i]` 个字符 **前面** 添加一个空格。  
索引从 0 开始计数，即 `spaces[i]` 是一个非负整数，表示在原始字符串中该位置之前插入空格。  
返回添加空格后的字符串。

**说明**：  
- `spaces` 中的位置是严格递增的。
- 每个位置只添加一个空格。

**示例**：

- 示例 1：

```text
输入: s = "LeetcodeHelpsMeLearn", spaces = [8,13,15]
输出: "Leetcode Helps Me Learn"
解释: 在索引 8 前加空格 → "Leetcode HelpsMeLearn"；在索引 13 前加空格 → "Leetcode Helps MeLearn"；在索引 15 前加空格 → "Leetcode Helps Me Learn"。
```

- 示例 2：

```text
输入: s = "icodeinpython", spaces = [1,5,7,9]
输出: "i code in py thon"
```

## 💻 解题思路
### 思路：双指针模拟（单次遍历）
#### 算法步骤
1. 初始化慢指针 `slow = 0` 指向 `spaces` 数组当前待插入空格的位置下标。
2. 初始化 `i = 0` 用于记录当前遍历原字符串的字符索引。
3. 创建一个空字符串 `ans` 作为结果。
4. 遍历原字符串 `s` 中的每个字符 `ch`：
   - 如果 `slow < len(spaces)` 且 `i == spaces[slow]`，说明需要在当前字符前插入空格，将空格追加到 `ans`，然后 `slow += 1`。
   - 将当前字符 `ch` 追加到 `ans`。
   - `i += 1`。
5. 返回 `ans`。

#### 代码实现
```python
from typing import List

class Solution:
    def addSpaces(self, s: str, spaces: List[int]) -> str:
        slow = 0
        l = len(spaces)
        i = 0
        ans = ""
        for ch in s:
            if slow < l and i == spaces[slow]:
                ans += " "
                slow += 1
            ans += ch
            i += 1
        return ans
```

#### 📊 性能分析
- 时间复杂度：$O(n)$，其中 $n$ 是字符串 `s` 的长度，只需一次遍历。
- 空间复杂度：$O(n)$，用于存储结果字符串（通常不计入额外空间，但新建字符串需 $O(n)$）。

#### 思考
您的解法使用双指针（一个指针遍历原字符串，一个指针遍历 `spaces` 数组），在遍历过程中判断是否需要在当前字符前加空格。由于 `spaces` 严格递增，`slow` 只向前移动，逻辑清晰且效率高。  
**注意**：`ans += " "` 在 Python 中可能产生较多临时对象，但字符串长度有限，不影响性能。若追求极致性能，可改用列表收集字符，最后 `join`。但您的代码简洁明了，是本题的标准解法之一。
