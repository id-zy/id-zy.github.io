# 数组异或操作

> **难度**：简单 | **题号**：1486 | **链接**：[1486. 数组异或操作](https://leetcode.cn/problems/xor-operation-in-an-array/) | **数据结构**：位运算、模拟

## 🎯 问题描述

**描述**：

给你两个整数 `n` 和 `start`。定义数组 `nums`：`nums[i] = start + 2*i`（下标从 0 开始，`n == nums.length`）。

请返回 `nums` 中所有元素按位异或（XOR）后的结果。

**示例 1**：

```text
输入：n = 5, start = 0
输出：8
解释：数组 nums = [0, 4, 6, 8, 10]，异或结果为 0 XOR 4 XOR 6 XOR 8 XOR 10 = 8。
```

**示例 2**：

```text
输入：n = 4, start = 3
输出：8
解释：数组 nums = [3, 5, 7, 9]，异或结果为 3 XOR 5 XOR 7 XOR 9 = 8。
```

**提示**：
- `1 <= n <= 1000`
- `0 <= start <= 1000`

## 💻 解题思路

### 思路 1：直接模拟（我的解法）

#### 核心逻辑

按定义逐项生成 `start + 2*i` 并累积异或，初值取 `start`（即第 0 项），循环从 1 到 n-1。

#### 代码实现

```python
class Solution:
    def xorOperation(self, n: int, start: int) -> int:
        ans = start
        for i in range(1, n):
            nums = start + 2 * i
            ans ^= nums
        return ans
```

```java
class Solution {
    public int xorOperation(int n, int start) {
        int ans = start;
        for (int i = 1; i < n; i++) {
            int nums = start + 2 * i;
            ans ^= nums;
        }
        return ans;
    }
}
```

#### 📊 性能分析

- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$（无需真的建数组）

#### 思考

- 这题存在 $O(1)$ 数学解：`start + 2*i = (start>>1 << 1) + ...`，把「偶数部分」与「最低位」拆开算，配合「0..m 的异或有周期为 4 的封闭公式」直接得出结果。面试时口头给出即可，工程上 $O(n)$ 模拟足够（n ≤ 1000）。
- 变量名 `nums` 容易误导——它其实只是「当前项」，叫 `cur` 更贴切。
- 同属「异或累积」家族：子数组异或查询、找出所有子集的异或总和再求和。

## 📝 总结

等差数列逐项异或，模拟即可；记住「不需要建数组、边算边累积」和「XOR 系列题常藏 O(1) 数学解」两点。
