# 对角线遍历

## 🎯 问题描述
**描述**：
给你一个大小为 `m x n` 的矩阵 `mat` ，请以对角线遍历的顺序，用一个数组返回这个矩阵中的所有元素。
**说明**：
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 104`
- `1 <= m * n <= 104`
- `-105 <= mat[i][j] <= 105`
**示例**：

- 示例 1：

```text
输入：mat = [[1,2,3],[4,5,6],[7,8,9]]
输出：[1,2,4,7,5,3,6,8,9]
```

- 示例 2：

```text
输入：mat = [[1,2],[3,4]]
输出：[1,2,3,4]
```
## 💻 解题思路
### 思路1：遍历
#### 代码实现
```python
class Solution:
    def findDiagonalOrder(self, mat: List[List[int]]) -> List[int]:
        if not mat or not mat[0]:
            return []
        m, n = len(mat), len(mat[0])
        ans = []
        row, col = 0, 0
        direction = 1  
        while len(ans) < m * n:
            ans.append(mat[row][col])
            if direction == 1:  
                new_row = row - 1
                new_col = col + 1
            else:  
                new_row = row + 1
                new_col = col - 1
            is_out_of_bounds = new_row < 0 or new_row >= m or new_col < 0 or new_col >= n
            if not is_out_of_bounds:
                row, col = new_row, new_col
            else:
                if direction == 1: 
                    if col + 1 < n:
                        col += 1
                    else:
                        row += 1
                else:  
                    if row + 1 < m:
                        row += 1
                    else:
                        col += 1
                direction *= -1
        return ans
```
