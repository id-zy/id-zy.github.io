# 位1的个数
## 🎯 问题描述
给定一个正整数 `n`，编写一个函数，获取一个正整数的二进制形式并返回其二进制表达式中 设置位 的个数（也被称为[汉明重量](https://baike.baidu.com/item/%E6%B1%89%E6%98%8E%E9%87%8D%E9%87%8F)）。
## 💻 代码实现
```python
class Solution:
    def hammingWeight(self, n: int) -> int:
         x= ''
         while n:
            a = n % 2
            n =n // 2
            x=str(a)+x
         num= x.count('1')
         return num
```
## 复杂度分析
- 时间复杂度$O(log(n))$
- 空间复杂度$O(1)$
