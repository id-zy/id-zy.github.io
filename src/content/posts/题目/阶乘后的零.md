# 阶乘后的零

## 🎯 问题描述
```text
给定一个整数n，返回 n! 结果中尾随零的数量。
提示 n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1
```
## 💻 代码实现
零的数量有2和5的对数决定，将问题转化求因子2的个数和因子5的个数，返回其最小值，但由于5的个数必定小于2的个数，所以只求5的个数
```python
class Solution:
    def trailingZeroes(self, n: int) -> int:
        if n<5:
            return 0
        m=0 
        a=5
        while a<=n:
            m+=n//a
            a*=5
        return m
```
