# 多数元素

## 🎯 问题描述
**描述**：
给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。
你可以假设数组是非空的，并且给定的数组总是存在多数元素。
**说明**：
- `n == nums.length`
- `1 <= n <= 5 * 104`
- `-109 <= nums[i] <= 109`
- 输入保证数组中一定有一个多数元素。

**示例**：

- 示例 1：

```text
输入：nums = [3,2,3]
输出：3
```

- 示例 2：

```text
输入：nums = [2,2,1,1,1,2,2]
输出：2
```
## 💻 解题思路
### 思路1：快速排序
#### 代码实现
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        nums.sort()
        return nums[len(nums)//2]
```
#### 📊 性能分析
##### 提交结果
- **运行时间**：0ms击败100.00%
- **内存消耗**：19.10MB击败26.44%
##### 复杂度验证
- 时间复杂度：$O(Nlogn)$
- 空间复杂度：$O(1)$
#### 思考
众数一定会出现在排序后的数组中间
### 思路2：哈希表
#### 代码实现
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        arr= defaultdict(int)
        for i in nums:
            arr[i]+=1
        n=len(nums)
        for i,count in arr.items():
            if count>n//2:
                return i
```
#### 📊 性能分析
##### 提交结果
- **运行时间**：7ms击败52.43%
- **内存消耗**：18.99MB击败59.30%
##### 复杂度验证
- 时间复杂度：$O(N)$
- 空间复杂度：$O(N)$
#### 思考
哈希表统计数字出现个数
