# 第三大的数

## 🎯 问题描述
给你一个非空数组，返回此数组中 **第三大的数** 。如果不存在，则返回数组中最大的数。
## 💻 代码实现
```python
class Solution:
    def thirdMax(self, nums: List[int]) -> int:
        max2=max(nums)
        max1=max(nums)
        if len(nums)<3:
            return max1
        pid=0
        while 1 :
            nums.remove(max1)
            if pid ==2 or len(nums)==0:
                break
            if max1!=max(nums):
                pid+=1
                max1=max(nums)
        if pid<2:
            return max2
        else:
            return max1
```
