# 196. 删除重复的电子邮箱

> **难度**：简单 | **题号**：196 | **链接**：[196. 删除重复的电子邮箱 - 力扣（LeetCode）](https://leetcode.cn/problems/delete-duplicate-emails/description/)

## 🎯 问题描述

**描述**：删除 Person 表中所有重复的电子邮箱，**只保留 id 最小**的那条。返回顺序不限。

**表：Person**

```text
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| email       | varchar |
+-------------+---------+
```

**示例 1**：

```text
输入：
Person 表:
+----+------------------+
| id | email            |
+----+------------------+
| 1  | john@example.com |
| 2  | bob@example.com  |
| 3  | john@example.com |
+----+------------------+
输出：
+----+------------------+
| id | email            |
+----+------------------+
| 1  | john@example.com |
| 2  | bob@example.com  |
+----+------------------+
```

**提示**：

- 这是**删除（DML）**题，不是查询：要用 `DELETE` + 自连接。
- 保留 id 最小的 → 删掉" email 相同且 id 更大"的行。

## 💻 解题思路

### 思路1：DELETE 自连接

#### 核心逻辑

`DELETE p1 FROM Person p1 JOIN Person p2`：把每一行 p1 与"同 email、id 更小"的 p2 配对，能配上的 p1 就是重复行，删之。保留条件是 `p1.id > p2.id`，与 查找重复的电子邮箱 的查询版成对。

#### 代码实现

```sql
# Write your MySQL query statement below
DELETE p1
from Person p1
join Person P2 where p1.email = p2.email and p1.id > P2.ID
```

#### 📊 性能分析

- 时间复杂度：$O(n^2)$（无索引自连接配对；email 建索引可降为 $O(n \log n)$）
- 空间复杂度：$O(1)$

#### 思考

- 8.0 也可用窗口函数：先 `ROW_NUMBER() OVER (PARTITION BY email ORDER BY id)`，再 DELETE rn > 1（DELETE 不能直接用窗口函数，需包一层子查询配合可更新视图写法）。

## 📝 总结

DELETE 去重三板斧：自连接配对 + 同值条件 + id 比较保留最小。
