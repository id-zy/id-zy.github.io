# 只出现一次的最大数字

> **难度**：简单 | **题号**：[619. Biggest Single Number](https://leetcode.cn/problems/biggest-single-number/) | **数据结构**：SQL（GROUP BY / HAVING / 子查询）

## 🎯 问题描述

**描述**：

表 `MyNumbers`：

| Column Name | Type |
| :--- | :--- |
| `num` | `int` |

- 该表可能包含重复项（**没有主键**），每一行含有一个整数。
- **单一数字**：在 `MyNumbers` 中**只出现一次**的数字。
- 找出**最大的单一数字**；如果不存在单一数字，**返回 `null`**。

**示例 1**：

```text
输入：MyNumbers
+-----+
| num |
+-----+
| 8   |
| 8   |
| 3   |
| 3   |
| 1   |
| 4   |
| 5   |
| 6   |
+-----+

输出：
+-----+
| num |
+-----+
| 6   |
+-----+

解释：单一数字有 1、4、5、6，其中 6 最大。
```

**示例 2**：

```text
输入：MyNumbers
+-----+
| num |
+-----+
| 8   |
| 8   |
| 7   |
| 7   |
| 3   |
| 3   |
| 3   |
+-----+

输出：
+------+
| num  |
+------+
| null |
+------+

解释：不存在单一数字，返回 null。
```

**提示**：
- 表可以没有主键，`num` 可重复。
- 结果必须是**一行**（没有答案时那一行的值是 `null`，而不是 0 行）。

## 💻 解题思路

### 思路 1：分组筛出单一数字 + 取最大（外层用 `SUM` 兜住空集）

#### 核心逻辑

1. `GROUP BY num` 把相同数字归成一组；
2. `HAVING COUNT(*) = 1` 只留下**只出现一次**的组，这就是全部「单一数字」；
3. `ORDER BY num DESC LIMIT 1` 取其中最大的一个；
4. 外层用 `SUM(num)` 包住子查询——**子查询为空（无单一数字）时，`SUM` 对空集返回 `NULL`，正好满足"返回 null"的要求**。

第 4 步是全题的关键，不是多余的包装：

| 写法 | 无单一数字时的结果 | 是否符合要求 |
| :--- | :--- | :--- |
| `SELECT num FROM (...) LIMIT 1` | **0 行**（结果集为空） | ❌ 要求返回一行 `null` |
| `SELECT SUM(num) FROM (...)` | **1 行，值为 `NULL`** | ✅ |
| `SELECT MAX(num) FROM (...)` | **1 行，值为 `NULL`** | ✅ 更直接 |
| `SELECT (SELECT num ... LIMIT 1) AS num` | **1 行，值为 `NULL`** | ✅ 标量子查询空集自动为 `NULL` |

因为子查询最多只有 1 行，`SUM(单行) == 该行的值`，所以用 `SUM` 取"值"是成立的。

#### 代码实现

```sql
# Write your MySQL query statement below
SELECT SUM(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1
    ORDER BY num DESC
    LIMIT 1
) t1;
```

等价且更短（直接靠聚合函数返回 `NULL`，省掉 `ORDER BY ... LIMIT`）：

```sql
SELECT MAX(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1
) t;
```

#### 📊 性能分析

- 时间复杂度：$O(n \log n)$——`GROUP BY` 若无索引需扫全表并可排序；外层只处理 ≤1 行。
- 空间复杂度：$O(k)$，$k$ 为不同 `num` 的个数（分组临时表）。
- 在 `num` 上建索引可把分组从排序变成有序扫描。

#### 思考

- **本题真正的考点不是 `GROUP BY`，而是"没有答案时怎么返回一行 `null`"。** 很多人写 `SELECT MAX(num) FROM MyNumbers GROUP BY num HAVING COUNT(*)=1;`——这在示例 2 会返回 **0 行**，判错。因为 `GROUP BY` 一旦过滤掉所有组，结果集就是空的，聚合函数根本没机会"对空集返回 NULL"。
- 记住这条区分：**`MAX`/`SUM` 的"空集返回 NULL"只在"聚合发生在最外层、且没有 `GROUP BY` 过滤掉全部行"时成立**。只要 `GROUP BY` 参与，空分组就等于空结果集。
- 「只出现一次」的判定有两条路：`HAVING COUNT(*) = 1`（分组计数）或 `num NOT IN (重复的数字)`（集合排除）。前者只需一次扫描，后者要额外的子查询或 `JOIN`，本题用前者。

## 📝 总结

1. 「只出现一次」= `GROUP BY num HAVING COUNT(*) = 1`。
2. 取最大：`MAX()` 或 `ORDER BY ... DESC LIMIT 1`。
3. **返回 `null` 的题，一定要确认答案会不会变成"0 行"**——把聚合函数放在最外层、或写标量子查询，是这个坑的标准解法。
