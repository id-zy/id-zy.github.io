# 185. 部门工资前三高的所有员工

> **难度**：困难 | **题号**：185 | **链接**：[185. 部门工资前三高的所有员工 - 力扣（LeetCode）](https://leetcode.cn/problems/department-top-three-salaries/)

## 🎯 问题描述

**描述**：找出每个部门中**薪资前三高**的所有员工（不同薪资为口径，并列都保留），返回部门名、员工名、薪水，按部门排序。

**表：Employee / Department**

```text
Employee 表:
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| name        | varchar |
| salary      | int     |
| departmentId| int     |
+-------------+---------+
Department 表:
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| id          | int     |
| name        | varchar |
+-------------+---------+
```

**示例 1**：

```text
输入：
Employee 表:
+----+-------+--------+--------------+
| id | name  | salary | departmentId |
+----+-------+--------+--------------+
| 1  | Joe   | 85000  | 1            |
| 2  | Henry | 80000  | 2            |
| 3  | Sam   | 60000  | 2            |
| 4  | Max   | 90000  | 1            |
| 5  | Janet | 69000  | 1            |
| 6  | Randy | 85000  | 1            |
| 7  | Will  | 70000  | 1            |
+----+-------+--------+--------------+
输出：
+------------+----------+--------+
| Department | Employee | Salary |
+------------+----------+--------+
| IT         | Max      | 90000  |
| IT         | Joe      | 85000  |
| IT         | Randy    | 85000  |
| IT         | Will     | 70000  |
| Sales      | Henry    | 80000  |
| Sales      | Sam      | 60000  |
+------------+----------+--------+
```

**提示**：

- "前三高"按**不同薪资**口径（90000、85000、70000 是 IT 前三，85000 两人并列都算）→ 对应 DENSE_RANK 而非 RANK/ROW_NUMBER。

## 💻 解题思路

### 思路1：相关子查询计数（用户解法）

#### 核心逻辑

对每行统计**同部门内比它高（含相等）的不同薪资个数**：`COUNT(DISTINCT t.salary) WHERE e.salary <= t.salary` ≤ 3 说明自己是前三档之一。并列自然保留，5.7 也能跑。

#### 代码实现

```sql
# Write your MySQL query statement below
select d.name as "Department",e.name as "Employee",e.salary
from Employee e
join Department d
on e.departmentId = d.id
where (SELECT count(distinct t.salary) FROM Employee t WHERE e.departmentId = t.departmentId and e.salary <= t.salary ) <=3
```

#### 📊 性能分析

- 时间复杂度：$O(n^2)$（相关子查询逐行计数）
- 空间复杂度：$O(1)$

### 思路2：DENSE_RANK 窗口函数（8.0 更优）

#### 核心逻辑

`DENSE_RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC)`，外层取 `rk <= 3`。与本题计数法等价，且 O(n log n) 一次排序完成，是面试首选写法（见 SQL-窗口函数）。

```sql
SELECT Department, Employee, Salary
FROM (
  SELECT d.name AS Department, e.name AS Employee, e.salary AS Salary,
         DENSE_RANK() OVER (PARTITION BY e.departmentId ORDER BY e.salary DESC) AS rk
  FROM Employee e JOIN Department d ON e.departmentId = d.id
) t
WHERE rk <= 3;
```

## 📝 总结

TopN 分组题标准结构：窗口函数排名 → 外层过滤 rk <= N；5.7 退化为相关子查询计数。
