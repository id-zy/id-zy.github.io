# 1283. 使结果不超过阈值的最小除数

## 🎯 问题描述
**描述**：  
给定一个整数数组 `nums` 和一个整数 `threshold`，请你选择一个正整数作为除数，将数组中的每个数除以该除数，并对结果向上取整，要求所有结果之和 **不超过** `threshold`。  
返回能够满足条件的最小除数。

**说明**：  
- 除法结果向上取整（`ceil`）。
- `1 <= nums.length <= 5 * 10^4`
- `1 <= nums[i] <= 10^6`
- `nums.length <= threshold <= 10^6`

**示例**：

- 示例 1：

```text
输入: nums = [1,2,5,9], threshold = 6
输出: 5
解释: 
  除数为 4 时，和为 ceil(1/4)+ceil(2/4)+ceil(5/4)+ceil(9/4) = 1+1+2+3 = 7 > 6，不满足。
  除数为 5 时，和为 1+1+1+2 = 5 ≤ 6，满足，且 5 是最小的。
```

- 示例 2：

```text
输入: nums = [44,22,33,11,1], threshold = 5
输出: 44
```

## 💻 解题思路
### 思路：二分查找（判定单调性）
#### 算法步骤
1. 确定二分查找的边界：
   - 左边界 `left = 0`（实际除数最小为 1，这里用 0 作为开区间左边界）
   - 右边界 `right = max(nums)`（当除数 ≥ max(nums) 时，每个数的 `ceil` 结果均为 1，总和为 `len(nums)`，一定 ≤ threshold，因为题目保证 `threshold ≥ len(nums)`）
2. 当 `left + 1 < right` 时循环（开区间 `(left, right]`）：
   - 计算中间值 `mid = (left + right) // 2`。
   - 判断以 `mid` 为除数是否满足条件：
     - 计算所有 `ceil(nums[i] / mid)` 的和，等价于 `sum((x - 1) // mid for x in nums) + len(nums)`。
     - 若该和 ≤ `threshold`，则 `right = mid`（缩小右边界，尝试更小的除数）。
     - 否则 `left = mid`（增大左边界）。
3. 循环结束时，`right` 即为满足条件的最小除数，返回 `right`。

#### 代码实现
```python
from typing import List

class Solution:
    def smallestDivisor(self, nums: List[int], threshold: int) -> int:
        left, right = 0, max(nums)
        while left + 1 < right:
            mid = (left + right) // 2
            # 判断条件：sum(ceil(nums[i]/mid)) <= threshold
            # ceil(x/mid) = (x-1)//mid + 1
            if sum((x - 1) // mid for x in nums) <= threshold - len(nums):
                right = mid
            else:
                left = mid
        return right
```

#### 📊 性能分析
- 时间复杂度：$O(n \log M)$，其中 $n$ 是数组长度，$M = \max(nums)$。二分查找执行 $\log M$ 次，每次计算和需要 $O(n)$。
- 空间复杂度：$O(1)$，仅使用常数个变量。

#### 思考
您的代码使用了一个巧妙的判定变形：`sum((x - 1) // mid) <= threshold - len(nums)` 等价于 `sum(ceil(x/mid)) <= threshold`，避免了浮点数运算，提高了精度和效率。二分查找的边界设置也很标准，左边界为 0（开区间），右边界为 `max(nums)`，最终返回 `right` 是满足条件的最小值。该解法是本题的推荐实现，简洁高效。
