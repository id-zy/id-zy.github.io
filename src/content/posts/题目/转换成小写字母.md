# 转换成小写字母

> **难度**：简单 | **题号**：709 | **链接**：[709. 转换成小写字母](https://leetcode.cn/problems/to-lower-case/) | **数据结构**：字符串

## 🎯 问题描述

**描述**：

给你一个字符串 `s`，将 `s` 中的大写字母转换成小写字母，其余字符保持不变，返回新字符串。

**示例 1**：

```text
输入：s = "Hello"
输出："hello"
```

**示例 2**：

```text
输入：s = "LOVELY"
输出："lovely"
```

**提示**：
- `1 <= s.length <= 100`
- `s` 由 ASCII 字符集中的可打印字符组成

## 💻 解题思路

### 思路 1：直接调用语言内置 API（我的解法）

#### 核心逻辑

Python 用 `s.lower()`，Java 用 `s.toLowerCase()`，一行完成。

#### 代码实现

```python
class Solution(object):
    def toLowerCase(self, s):
        return s.lower()
```

```java
class Solution {
    public String toLowerCase(String s) {
        String lowstr = s.toLowerCase();
        return lowstr;
    }
}
```

> 📌 原稿 Python 里第一行 `return lower(s)` 是笔误——Python 没有内置 `lower()` 函数（会 `NameError`，正确写法是字符串方法 `s.lower()`），且后面还跟着一个永远执行不到的 `return s.lower()`，已合并为上面一行。

#### 📊 性能分析

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$（新字符串）

#### 思考

- 不用内置 API 的手动写法（面试常要求）：遍历字符，`'A' <= c <= 'Z'` 时转小写：

  ```python
  class Solution(object):
      def toLowerCase(self, s):
          return ''.join(
              chr(ord(c) + 32) if 'A' <= c <= 'Z' else c
              for c in s
          )
  ```

- 原理：ASCII 中大小写字母相差 **32**（`0x20`），即第 6 个二进制位——大写字母该位为 0，小写为 1，`OR 0x20` 即可把大写转小写。
- 进阶：Python 的 `str.lower()` 比 ASCII 转换处理面广得多（Unicode 全角、土耳其语等场景不同），本题只涉及 ASCII。

## 📝 总结

API 一行过；但「+32 / OR 0x20」的 ASCII 手动转换是这道题真正的考点，面试官出这题多半就是想看这个。
