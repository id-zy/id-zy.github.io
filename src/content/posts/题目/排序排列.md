# 排序排列

> **难度**：中等 | **题号**：3644 | **链接**：[3644. 排序排列](https://leetcode.cn/problems/maximum-k-to-sort-a-permutation/) | **数据结构**：位运算、贪心

## 🎯 问题描述

**描述**：

给你一个长度为 `n` 的整数数组 `nums`，其中 `nums` 是范围 `[0, n-1]` 内所有数字的一个**排列**。你可以在满足 `nums[i] AND nums[j] == k` 的情况下交换下标 `i` 和 `j` 的元素（`AND` 为按位与，`k` 是非负整数）。

返回可以使数组按**非递减**顺序排序的**最大值** `k`（允许任意次交换）。如果 `nums` 已经有序，返回 `0`。

**示例 1**：

```text
输入：nums = [0,3,2,1]
输出：1
解释：选择 k = 1，交换 3 和 1（3 AND 1 == 1），得到 [0,1,2,3]。
```

**示例 2**：

```text
输入：nums = [0,1,3,2]
输出：2
解释：选择 k = 2，交换 3 和 2（3 AND 2 == 2），得到 [0,1,2,3]。
```

**示例 3**：

```text
输入：nums = [3,2,1,0]
输出：0
解释：任何 k > 0 都无法完成排序，只能选 k = 0。
```

**提示**：
- `1 <= n == nums.length <= 10^5`
- `nums` 是 `0` 到 `n-1` 的一个排列

## 💻 解题思路

### 思路 1：所有错位元素的按位与（我的解法）

#### 核心逻辑

- 结论：答案 = **所有不在自己位置上的元素的按位与**（把每个 `nums[i] != i` 的 `nums[i]` 全部 `AND` 起来）；已经有序时结果为 0。
- 原理（贪心 + 位运算性质）：
  - 设 `k` 为全部错位元素的 AND。`k` 的每一个为 1 的位，在**每一个**错位元素上都为 1，因此任意两个错位元素 `a`、`b` 都满足 `a AND b` 包含 `k` 的所有位——总能通过以 `k` 为桥的交换链把每个错位元素换回原位；
  - 反过来，`k` 不可能再大：若答案为 `k'`，任意两个需要互相交换的错位元素 `a`、`b` 必须满足 `a AND b == k'`，而 `k'` 只能由「所有交换会涉及的元素」公共拥有的位组成——正是全部错位元素的 AND。

#### 代码实现

```python
class Solution:
    def sortPermutation(self, nums: List[int]) -> int:
        if nums[0] != 0:
            return 0
        ans = -1
        for i, num in enumerate(nums):
            if i != num:
                ans &= num
        return max(ans, 0)
```

```java
class Solution {
    public int sortPermutation(int[] nums) {
        int ans = -1;
        for (int i = 0; i < nums.length; i++) {
            int num = nums[i];
            if (i != num) {
                ans &= num;
            }
        }
        return Math.max(ans, 0);
    }
}
```

#### 📊 性能分析

- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

#### 思考

- Python 解里 `if nums[0] != 0: return 0` 这个剪枝是**正确**的，且值得记住推理：若 `nums[0] != 0`，说明值 `0` 不在下标 0——而 `0` 必须落回下标 0 才算归位，所以 `0` 一定出现在某个错位位置上、必然进入按位与集合，结果只能是 0，可提前返回。
- `ans` 初始化为 `-1`（二进制全 1）是位运算累积 AND 的惯用写法；全有序时没有任何 AND 发生，`ans` 保持 -1，用 `max(ans, 0)` 兜底为 0——负数 AND 初值这个坑容易忘。
- 对错位**下标**做 AND 也是常见等价写法（排序后 `i` 位应放 `i`），两种写法在本题都可通过。

## 📝 总结

排列类位运算题先看「错位集合」：答案往往就是错位元素的 AND（本题）或 XOR（异或系列）。`-1` 当 AND 初值 + `max(·, 0)` 兜底，是这个套路的标准模板。
