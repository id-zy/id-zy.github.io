# 有趣的电影

## 🎯 问题描述
表：`cinema`
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| id             | int      |
| movie          | varchar  |
| description    | varchar  |
| rating         | float    |
+----------------+----------+
id 是该表的主键(具有唯一值的列)。
每行包含有关电影名称、类型和评级的信息。
评级为 [0,10] 范围内的小数点后 2 位浮点数。
编写解决方案，找出所有影片描述为 **非** `boring` (不无聊) 的并且 **id 为奇数** 的影片。
返回结果按 `rating` **降序排列**。
## 💻 代码实现
```sql
# Write your MySQL query statement below
SELECT t1.id,t1.movie,t1.description,t1.rating
FROM cinema t1
WHERE t1.description!='boring' and t1.id&1=1
ORDER BY t1.rating DESC
```
