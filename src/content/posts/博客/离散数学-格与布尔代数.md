# 格与布尔代数：链为什么不是布尔格

这道题不长：

> 设 $\langle L, \le \rangle$ 是一条链，$|L| \ge 3$，则 $\langle L, \le \rangle$ 是____。
> A. 不是格　B. 是有补格　C. 是分配格　D. 是布尔格

正确答案是 C。我第一次选了 D，理由是「链是格、链满足分配律，那不就是布尔格吗」。

这个推理错在一个很朴素的地方：**布尔格不是「分配格」的加强版，而是「分配」和「有补」两条性质同时成立**。链只满足了前一条。两条性质互相独立这件事，光靠记定义容易含糊，跑一遍小格的枚举就很清楚。

## 一、格：任意两元素都有上下确界

格的定义落在偏序集上：任意两个元素 $a, b$ 都有**最小上界**（并，$a \vee b$）和**最大下界**（交，$a \wedge b$）。

这两个运算自动满足一组性质：交换律、结合律、**吸收律**（$a \wedge (a \vee b) = a$，$a \vee (a \wedge b) = a$）。反过来说，任何满足这组性质的代数结构都能诱导出一个偏序，两种视角等价。

链是最简单的格：全序集里任意两元素都可比，所以 $\sup\{a,b\} = \max\{a,b\}$、$\inf\{a,b\} = \min\{a,b\}$，上下确界总是存在。「链不是格」这个说法不成立。

## 二、分配格：两个式子验一个就够

分配格要求交对并、并对交都可分配：

$$a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$$
$$a \vee (b \wedge c) = (a \vee b) \wedge (a \vee c)$$

两个式子不必都验——由吸收律可以互推，验一个另一个自动成立。

链一定是分配格，理由可以直接算：

$$a \wedge (b \vee c) = \min\{a, \max\{b,c\}\} = \max\{\min\{a,b\}, \min\{a,c\}\} = (a \wedge b) \vee (a \wedge c)$$

这是分类讨论的结论（三种大小关系各验一次），不是巧合。所以「每个链都是分配格」是真命题。

分配律之所以重要，是因为它决定了能不能「像集合那样做代数化简」——有它才能谈析取/合取范式，才能构造布尔代数。

## 三、有补格：先有界，再配对

有补格是两个条件叠起来的：先得有**界**（存在最大元 $1$ 和最小元 $0$），再要求每个元素 $x$ 都存在补元 $y$ 使

$$x \vee y = 1,\quad x \wedge y = 0.$$

「有补」对应逻辑里的「非」、集合里的「补集」，这是布尔代数能做真假取反的来源。

判定步骤也很机械：找到哈斯图最底和最顶确认有界，然后对中间每个元素试着配一个补元。有一个配不上，就不是有补格。

## 四、四个格的体检

把「分配」和「有补」写成可执行的判定，跑五个小格：

```python
from itertools import product

def lattice(elems, cover):
    le = {(x, x) for x in elems} | set(cover)
    while True:
        new = {(a, d) for a, b in le for c, d in le if b == c} - le
        if not new:
            break
        le |= new
    def sup(x, y):
        ups = [z for z in elems if (x, z) in le and (y, z) in le]
        return next(z for z in ups if all((z, w) in le for w in ups))
    def inf(x, y):
        ds = [z for z in elems if (z, x) in le and (z, y) in le]
        return next(z for z in ds if all((w, z) in le for w in ds))
    return le, sup, inf

def report(name, elems, cover):
    le, sup, inf = lattice(elems, cover)
    dist = all(inf(a, sup(b, c)) == sup(inf(a, b), inf(a, c))
               for a, b, c in product(elems, repeat=3))
    bot = next(x for x in elems if all((x, y) in le for y in elems))
    top = next(x for x in elems if all((y, x) in le for y in elems))
    comp = all(any(sup(x, y) == top and inf(x, y) == bot for y in elems) for x in elems)
    print(f"  {name:<12}{len(elems):>4}{'是' if dist else '否':>6}"
          f"{'是' if comp else '否':>6}{'是' if dist and comp else '否':>6}")

print(f"  {'格':<10}{'元素':>4}{'分配':>6}{'有补':>6}{'布尔':>6}")
report("M3 钻石格", ["0", "a", "b", "c", "1"],
       [("0", "a"), ("0", "b"), ("0", "c"), ("a", "1"), ("b", "1"), ("c", "1")])
report("N5 五角格", ["0", "a", "b", "c", "1"],
       [("0", "a"), ("a", "b"), ("b", "1"), ("0", "c"), ("c", "1")])
report("3 元链", ["0", "a", "1"], [("0", "a"), ("a", "1")])
report("2 元链", ["0", "1"], [("0", "1")])
report("B2 幂集格", ["∅", "{1}", "{2}", "{1,2}"],
       [("∅", "{1}"), ("∅", "{2}"), ("{1}", "{1,2}"), ("{2}", "{1,2}")])
```

```text
  格           元素    分配    有补    布尔
  M3 钻石格         5     否     是     否
  N5 五角格         5     否     是     否
  3 元链           3     是     否     否
  2 元链           2     是     是     是
  B2 幂集格         4     是     是     是
```

这张表把「互相独立」摆得很明白：**M3 和 N5 占了「有补」丢了「分配」，3 元链占了「分配」丢了「有补」**，只有 2 元链和 B2 两条都占。四行里，「分配」和「有补」的四种组合各有实例——这就是它们互相独立的意思。

那道题里，$|L| \ge 3$ 的链正好落在第三行：分配但不有补。

## 五、M3：有补，但分配失败

钻石格 M3 的元素是 $\{0, a, b, c, 1\}$，其中 $a, b, c$ 两两不可比，各自与 $0$、$1$ 相连。它有补——$a$ 的补可以是 $b$ 也可以是 $c$（两个都满足 $a \vee x = 1$、$a \wedge x = 0$）。

但分配律当场失效：

```python
join = {("a", "b"): "1", ("a", "c"): "1", ("b", "c"): "1",
        ("a", "1"): "1", ("b", "1"): "1", ("c", "1"): "1",
        ("a", "0"): "a", ("b", "0"): "b", ("c", "0"): "c"}
meet = {("a", "b"): "0", ("a", "c"): "0", ("b", "c"): "0",
        ("a", "1"): "a", ("b", "1"): "b", ("c", "1"): "c",
        ("a", "0"): "0", ("b", "0"): "0", ("c", "0"): "0"}

def j(x, y):
    return x if x == y else (join.get((x, y)) or join.get((y, x)))

def m(x, y):
    return x if x == y else (meet.get((x, y)) or meet.get((y, x)))

lhs = m("a", j("b", "c"))
rhs = j(m("a", "b"), m("a", "c"))
print(f"  a ∧ (b ∨ c) = a ∧ {j('b', 'c')} = {lhs}")
print(f"  (a ∧ b) ∨ (a ∧ c) = {m('a', 'b')} ∨ {m('a', 'c')} = {rhs}")
print(f"  {lhs} ≠ {rhs}")
```

```text
  a ∧ (b ∨ c) = a ∧ 1 = a
  (a ∧ b) ∨ (a ∧ c) = 0 ∨ 0 = 0
  a ≠ 0
```

左边得 $a$、右边得 $0$，不相等。原因很直观：$b \vee c = 1$ 把两个「兄弟」合并到顶，$a$ 再交上去就还是 $a$；而 $a$ 与 $b$、$a$ 与 $c$ 分别相交都是 $0$，两个 $0$ 并起来还是 $0$。**「先并再交」和「先交再并」在 M3 上走的不是同一条路。**

顺带一个判定捷径：**格是分配格，当且仅当它不含 M3 或 N5 作为子格**。所以看到哈斯图里有钻石形或五角形，直接判非分配，不用代入公式算。

## 六、链：分配，但补不出来

反过来，$|L| \ge 3$ 的链是分配格，却配不出补元。

```python
chain = ["0", "a", "1"]
rank = {"0": 0, "a": 1, "1": 2}

def sup(x, y):
    return x if rank[x] > rank[y] else y

def inf(x, y):
    return x if rank[x] < rank[y] else y

cands = [y for y in chain if sup("a", y) == "1"]
print(f"  要 a∨y = 1，候选 y 只有 {cands}")
print(f"  此时 a∧1 = {inf('a', '1')}，不等于最小元 0")
print(f"  所以 a 没有补元，链不是有补格")
```

```text
  要 a∨y = 1，候选 y 只有 ['1']
  此时 a∧1 = a，不等于最小元 0
  所以 a 没有补元，链不是有补格
```

中间那个元素 $a$ 想找补元，先得让 $a \vee y = 1$。链里能把它抬到 $1$ 的只有 $1$ 自己（$a \vee 0 = a$、$a \vee a = a$），可 $a \wedge 1 = a \neq 0$。所以 $a$ 配不上补元。

**链越长越补不了**——元素一多，中间那一串都卡在同一个死结上。这也是为什么 2 元链反而是布尔代数：它没有「中间元素」，$0$ 和 $1$ 互为补元，两条性质都满足。

## 七、布尔格：分配且每元有补

定义到这里自然浮出来：

> 布尔格 = **有补的分配格**。

两条缺一不可，前面四个格已经演示过。补元还有一个性质用得上：在分配格里补元是**唯一**的（M3 里 $a$ 有两个补，这正是它非分配的表现）。

布尔代数就是带补运算的布尔格 $\langle A, \vee, \wedge, \overline{\phantom{x}} \rangle$。它的结构定理很短，但约束极强：

1. 有限布尔代数的载体元素个数必是 $2$ 的幂次；
2. 对每个正整数 $n$，都存在 $2^n$ 个元素的布尔代数；
3. 元素个数相同的有限布尔代数彼此同构。

第 1 条的用处是**直接排除**：看到「有 10 个元素的布尔代数」，不用验分配律和有补性，直接判不存在。第 3 条更彻底——元素数一定，结构就定了，研究任何 $2^n$ 元布尔代数等价于研究某个 $n$ 元集合的幂集代数 $\langle \mathcal{P}(X), \cup, \cap, \complement \rangle$。

表里那个 2 元链就是 $n=1$ 的情形（$2^1 = 2$），B2 幂集格是 $n=2$（$2^2 = 4$）。

## 八、自然偏序：把序关系翻译成等式

布尔代数上本来没有「大小」，但可以由交并诱导出来：

$$a \le b \iff a \wedge b = a \iff a \vee b = b.$$

更有用的是这个判定式：

$$b \wedge \bar{c} = 0 \iff b \le c.$$

两个方向都能纯代数地推出来。正向：由 $b \le c$ 得 $b \wedge c = b$，于是

$$b \wedge \bar{c} = (b \wedge c) \wedge \bar{c} = b \wedge (c \wedge \bar{c}) = b \wedge 0 = 0.$$

反向：从 $b \wedge \bar{c} = 0$ 出发，

$$b = b \wedge 1 = b \wedge (c \vee \bar{c}) = (b \wedge c) \vee (b \wedge \bar{c}) = (b \wedge c) \vee 0 = b \wedge c,$$

得到 $b \wedge c = b$，这正是 $b \le c$ 的定义。

在 4 元幂集格上枚举所有 $(b,c)$ 对，等价关系应当处处成立：

```python
from itertools import product

U = {"∅": set(), "{1}": {1}, "{2}": {2}, "{1,2}": {1, 2}}
ok = 0
for b, c in product(U, repeat=2):
    lhs = U[b] & (U["{1,2}"] - U[c]) == set()
    rhs = U[b] <= U[c]
    ok += (lhs == rhs)
print(f"  {len(U) ** 2} 个 (b, c) 对，等价成立 {ok}/{len(U) ** 2}")
```

```text
  16 个 (b, c) 对，等价成立 16/16
```

这个式子的实际价值是**免画图**：题目给的往往是等式（如 $b \wedge \bar{c} = 0$），要求推出序关系；有了等价式就能直接互译，不用画哈斯图。

顺带一个语义直觉：$b \wedge \bar{c} = 0$ 意思是「$b$ 里面没有跑出 $c$ 的部分」，也就是 $b$ 蕴含 $c$。集合论里对应的说法是 $B \cap C^c = \varnothing \iff B \subseteq C$，两者同构。

## 九、小结

- **布尔格不是分配格的加强版**，是「分配 ∧ 有补」的合取。这道题错在把合取当成蕴含。
- **两条性质互相独立**，四个格给足了反例：3 元链分配但不有补，M3 与 N5 有补但不分配，只有 2 元链和 B2 都占。
- **M3 的失效点很具体**：$b \vee c = 1$ 把兄弟并到顶，$a$ 再交还是 $a$；而分别交都是 $0$。先并再交 ≠ 先交再并。
- **判定捷径**：哈斯图里出现钻石形或五角形，直接判非分配。
- **链补不出来的根因**：中间元素的 $a \vee y = 1$ 只能取 $y = 1$，而 $a \wedge 1 = a \neq 0$。所以链越长越补不了，2 元链反而是布尔代数。
- **有限布尔代数元素数必为 $2^n$ 且同构唯一**：数一下元素个数就能排除一大半，不必验公理。
- **$b \wedge \bar{c} = 0 \iff b \le c$** 把序关系翻译成等式，16 个对全部成立，作用是不用画图。
