# 代数结构阶梯：一条公理换一个名字

一个集合配一个运算，看起来什么都能叫「系统」。但数学要给它们分级：封闭算入场，结合律、幺元、逆元一层层加上去，名字就依次变成半群、独异点、群。

这套阶梯的价值不在记名字，而在**定位**。拿到一个陌生的运算，先问它满足到哪一层，能用的定理就到哪一层为止：半群里不能用消去律，独异点里不能约分，群里的每个元素都能被「撤销」。

下面按阶梯往上走，每一层只加一条要求，并附一段可运行的检查。最后两级是抽象代数真正的分水岭：一个运算撑到「群」，两个运算撑到「环」和「域」。

## 一、阶梯只有一条主线

| 结构 | 载体与运算 | 比上一层多要求 | 典型例子 |
| :--- | :--- | :--- | :--- |
| 代数系统 | 非空集合 + 封闭运算 | — | $\langle \mathbb{N}, + \rangle$ |
| 半群 | 一个二元运算 | 结合律 | $\langle \mathbb{N}, + \rangle$ |
| 独异点 | 一个二元运算 | 幺元 | $\langle \mathbb{N}, + \rangle$，幺元 $0$ |
| 群 | 一个二元运算 | 每个元素有逆元 | $\langle \mathbb{Z}, + \rangle$ |
| 环 | 两个运算 | 加法成群、乘法半群、分配律 | $\langle \mathbb{Z}, +, \cdot \rangle$ |
| 域 | 两个运算 | 非零元对乘法成群 | $\langle \mathbb{Q}, +, \cdot \rangle$ |

注意 $\langle \mathbb{N}, + \rangle$ 同时是半群和独异点，但它不是群：$3$ 在自然数里没有加法逆元。同一个载体换个运算结论就变，$\langle \mathbb{N}, \cdot \rangle$ 的幺元是 $1$ 而不是 $0$。

阶梯上的判定顺序是固定的：**先确认封闭，再查结合，再找幺元，最后验逆元**。顺序不能换，因为后一条的表述都建立在前一条之上——没有幺元，「逆元」这两个字根本没有意义。

## 二、封闭性：先得有「运算」

代数系统是一个非空集合 $A$ 连同定义在它上面的若干运算 $f_1, f_2, \dots, f_n$，记为 $\langle A, f_1, \dots, f_n \rangle$。它由四样东西构成：载体（集合本身）、运算、运算满足的公理、代数常元。

关键是运算要**封闭**：$n$ 元运算 $f: A^n \to A$ 的值域落在 $A$ 里，才算 $A$ 上的运算。写成映射 $f: A^n \to B$ 而 $B \subset A$，就叫在 $A$ 上封闭。

自然数上的减法是最常见的反例：$3 - 5 = -2$ 掉出了 $\mathbb{N}$，所以 $\langle \mathbb{N}, - \rangle$ 连代数系统都不是。这也是为什么减法、除法在抽象代数里总要改写成「加负数」「乘倒数」——把不封闭的运算换成封闭的运算，阶梯才开始起作用。

封闭性容易被当成废话跳过，它其实是整套体系的地基：没有它，结合律 $a*(b*c)=(a*b)*c$ 左边的 $(b*c)$ 都不一定还在集合里，写出来就是空话。

## 三、半群：只要结合律

代数系统 $\langle S, * \rangle$ 若满足结合律，即对任意 $x, y, z \in S$ 有 $(x*y)*z = x*(y*z)$，就称它是半群。矩阵乘法、字符串拼接、函数复合都是半群，它们都满足结合律，但都没有「逆」。

半群里有个不显眼但好用的结论：**有限半群中每个元素都有幂等幂**。也就是对任意 $a$，总存在正整数 $n$ 使 $(a^n)^2 = a^n$。

证明只用一行鸽巢：序列 $a, a^2, a^3, \dots$ 全在有限集合里，必有 $a^i = a^j$（$i < j$）。取 $p = j - i > 0$，则 $a^i = a^{i+p}$，从这一项起序列进入周期，周期末端的幂就是幂等的。

拿 $A = \{0,1\}$ 上全部 4 个函数（运算为复合）验证，每个函数几次幂之后就落进幂等元：

```python
A = (0, 1)
funcs = [(f0, f1) for f0 in A for f1 in A]      # 元素写成 (f(0), f(1))

def comp(f, g):
    return tuple(f[g[x]] for x in A)             # (f∘g)(x) = f(g(x))

for f in funcs:
    cur, hit = f, None
    for k in range(1, 20):
        if comp(cur, cur) == cur:
            hit = k
            break
        cur = comp(cur, cur)
    print(f"f={f} 的 {hit} 次幂是幂等元:", comp(cur, cur) == cur)
```

```text
f=(0, 0) 的 1 次幂是幂等元: True
f=(0, 1) 的 1 次幂是幂等元: True
f=(1, 0) 的 2 次幂是幂等元: True
f=(1, 1) 的 1 次幂是幂等元: True
```

$(1,0)$ 是「取反」，平方之后变成恒等函数，所以它的 2 次幂幂等；两个常值函数本身就是幂等的，1 次幂就够了。

## 四、独异点：找回那个「什么都不做」的元素

半群再加一条：存在幺元 $e$，使 $e*x = x*e = x$。这时的结构叫独异点（幺半群）。$\langle \mathbb{N}, + \rangle$ 的幺元是 $0$，$\langle \mathbb{N}, \cdot \rangle$ 的是 $1$，字符串拼接的是空串。

幺元的定义拆成左右两半时有个小定理：**若左幺元 $e_l$ 与右幺元 $e_r$ 同时存在，则 $e_l = e_r$，且幺元唯一**。一行就够：

$$e_l = e_l * e_r = e_r$$

第一步因为 $e_r$ 是右幺元，第二步因为 $e_l$ 是左幺元。所以只需要验一侧，另一侧会自动成立——前提是集合上这个运算确实可结合。

函数复合是独异点里最典型的一个：集合 $A$ 上所有函数 $A^A$ 关于复合，幺元是恒等函数 $id_A$，因为 $id_A \circ f = f \circ id_A = f$。但它**不是群**：常值函数没有逆。只有双射才有逆函数，把 $A^A$ 换成 $A$ 上全体双射，才升级成群，也就是对称群 $S_A$。

这一层最容易出错的地方，是把「有幺元」当成「有逆元」。恒等函数的存在只保证「什么都不做」是合法的，不保证「做了能撤回」。

## 五、群：每个元素都能被撤销

独异点再加最后一条：每个元素 $x$ 都有逆元 $x^{-1}$ 使 $x * x^{-1} = x^{-1} * x = e$，就得到群。整数加法群、非零有理数乘法群、3 位二进制串关于异或、$A$ 上的双射关于复合，都是群。

群的四条性质都能从逆元直接推出来，值得记住的是推导方式而不是结论：

- **逆元唯一**：若 $x*y = e$ 且 $x*z = e$，两边左乘 $x^{-1}$ 即得 $y = z$。
- **幂等元唯一**：若 $a*a = a$，左乘 $a^{-1}$ 得 $a = e$。群把幂等元压成了唯一一个。
- **消去律**：$a*b = a*c$ 两边左乘 $a^{-1}$ 得 $b = c$。半群没有这条，所以它才是群的特权。
- **无零元**（$|G| > 1$）：若存在零元 $\theta$ 使 $\theta * x = \theta$，又因 $\theta$ 可逆，两边乘 $\theta^{-1}$ 得 $x = e$，于是全群只剩一个元素。

还有一条结构性的事实：**群运算表的每一行、每一列都是全体元素的一个置换**。因为固定 $a$ 时，$x \mapsto a*x$ 既是单射（消去律）又是有限集上的自映射，必然满射。这条在 $(\mathbb{Z}_5, +)$ 上肉眼可验：

```python
n = 5
for a in range(n):
    row = [(a + b) % n for b in range(n)]
    print("行", a, row, "是置换:", sorted(row) == list(range(n)))
```

```text
行 0 [0, 1, 2, 3, 4] 是置换: True
行 1 [1, 2, 3, 4, 0] 是置换: True
行 2 [2, 3, 4, 0, 1] 是置换: True
行 3 [3, 4, 0, 1, 2] 是置换: True
行 4 [4, 0, 1, 2, 3] 是置换: True
```

顺带一个判别技巧：如果写出来的运算表某一行有两个相同元素，那它一定不是群，连消去律都不满足，不用再查别的。

## 六、子群：两条判定只做一半

$G$ 的非空子集 $H$ 若在 $G$ 的运算下也成群，则称 $H$ 是 $G$ 的子群，记 $H \le G$。直接按定义验要查结合律、幺元、逆元三件事，实际有两条更省的路。

**判定一**：$H$ 非空，且对任意 $a, b \in H$ 有 $a*b \in H$、$a^{-1} \in H$，则 $H \le G$。结合律是从 $G$ 继承的，不用验；幺元由 $a * a^{-1}$ 自动落在 $H$ 里。

**判定二**（更短）：$H$ 非空，且对任意 $a, b \in H$ 有 $a * b^{-1} \in H$，则 $H \le G$。一条条件同时管了乘法与逆元。

**有限子集还能再省**：$G$ 是群，$H$ 是 $G$ 的有限非空子集，只要 $H$ 对运算封闭就是子群。理由还是鸽巢：取 $a \in H$，$a, a^2, a^3, \dots$ 全在有限的 $H$ 里，必有 $a^i = a^j$，于是 $a^{j-i} = e \in H$，而 $a^{j-i-1}$ 就是 $a$ 的逆元。

拿 $\mathbb{Z}_6$ 加法验一下 $H = \{0, 3\}$：$3+3 = 6 \equiv 0$、$0+3 = 3$，封闭；$0$ 与 $3$ 都自逆。所以它是子群，虽然它不是「$0$ 到 $k$ 的一段」。任何群都有两个平凡子群：$\{e\}$ 和 $G$ 本身。

## 七、两个运算：环与零因子

一个运算到群就到顶了。要描述整数、多项式这些带两种运算的对象，得换一套要求：$\langle A, +, \cdot \rangle$ 是环，条件是 $\langle A, + \rangle$ 为阿贝尔群、$\langle A, \cdot \rangle$ 为半群、乘法对加法可分配。

加法成群带来一整套免费结论：零元 $\theta$ 唯一、每个元素有相反数、可以移项。配上分配律，还能推出 $a \cdot \theta = \theta$、$a \cdot (-b) = -(a \cdot b)$、$(-a) \cdot (-b) = a \cdot b$ 这些「符号法则」——它们在中学是规定，在环里是定理。

乘法那一半只是半群，所以差异全在这里。若存在非零的 $a, b$ 使 $a \cdot b = \theta$，就称 $a$、$b$ 为零因子；没有零因子的环叫无零因子环，它与「乘法满足可约律（$c \ne \theta$ 时 $c \cdot a = c \cdot b \Rightarrow a = b$）」等价。

把 $\mathbb{Z}_n$ 从 2 跑到 10，两条运算的差别一目了然：

```python
from math import gcd

print(" n | 加成群 | 乘是独异点 | 可逆元数 | 有零因子 | 非零元成群")
for n in range(2, 11):
    elems = range(n)
    add_group = all(any((a + b) % n == 0 for b in elems) for a in elems)
    mul_closed = all((a * b) % n in elems for a in elems for b in elems)
    assoc = all(((a * b) * c) % n == (a * (b * c)) % n
                for a in elems for b in elems for c in elems)
    monoid = mul_closed and assoc and all((a * 1) % n == a for a in elems)
    u = [a for a in range(1, n) if gcd(a, n) == 1]
    zero_div = any(a and b and (a * b) % n == 0
                   for a in range(1, n) for b in range(1, n))
    print(f"{n:>2} |   {add_group}   |    {monoid}     |    {len(u):>2}    |   {zero_div}    |   {monoid and len(u) == n - 1}")
```

```text
 n | 加成群 | 乘是独异点 | 可逆元数 | 有零因子 | 非零元成群
 2 |   True   |    True     |     1    |   False    |   True
 3 |   True   |    True     |     2    |   False    |   True
 4 |   True   |    True     |     2    |   True    |   False
 5 |   True   |    True     |     4    |   False    |   True
 6 |   True   |    True     |     2    |   True    |   False
 7 |   True   |    True     |     6    |   False    |   True
 8 |   True   |    True     |     4    |   True    |   False
 9 |   True   |    True     |     6    |   True    |   False
10 |   True   |    True     |     4    |   True    |   False
```

加那一列永远为真——模 $n$ 加法对任何 $n$ 都成群。乘那一列也永远为真，因为 $1$ 总是幺元。翻脸的是后三列：合数一旦出现零因子，可逆元就凑不满 $n-1$ 个。

$n = 9$ 这一行值得多看一眼：可逆元有 6 个（$\varphi(9) = 6$），数量不少，但 $3 \cdot 3 = 9 \equiv 0$，$3$ 是零因子，非零元照样成不了群。**可逆元多，不等于剩下的元素就不是零因子。**

交换、含幺、无零因子的环另有名字：整环。整数环 $\mathbb{Z}$、多项式环 $\mathbb{Z}[x]$ 都是整环，而 $\mathbb{Z}_6$ 不是——它有两个零因子 $2$ 和 $3$。

## 八、域：乘法也能撤销

域是最紧的一层：$\langle F, + \rangle$ 是阿贝尔群，去掉零元后的 $\langle F - \{\theta\}, \cdot \rangle$ 也是阿贝尔群，再加分配律。等价说法是「$|F| > 1$ 的整环，且每个非零元都有乘法逆元」。

显然域一定是整环：非零元都能逆，自然不可能有零因子（$a \cdot b = 0$ 且 $a \ne 0$ 时左乘 $a^{-1}$ 得 $b = 0$）。反过来**只有加上有限性才成立**：

- **有限整环必为域**。取非零元 $a$，映射 $x \mapsto a \cdot x$：若 $a x = a y$，则 $a(x - y) = 0$，无零因子且 $a \ne 0$ 故 $x = y$，是单射；有限集上单射即满射，于是存在 $b$ 使 $a b = 1$，$a$ 可逆。
- **无限整环不一定是域**。$\mathbb{Z}$ 是整环，但 $2$ 的逆 $\frac{1}{2}$ 不在 $\mathbb{Z}$ 里；$\mathbb{Z}[\sqrt{3}]$ 同样是整环而非域。

那段证明里唯一用到「有限」的地方，是「单射推满射」。这个跳步在无限集上直接失效，所以 $\mathbb{Z}$ 才卡在整环。

单射这一步在零因子面前具体是怎么塌的，把「乘 2」这个映射在两个环上各打一遍就看到了：

```python
for n in (6, 7):
    img = [(2 * x) % n for x in range(n)]
    print(f"Z_{n} 的像 = {img}   单射 = {len(set(img)) == n}")
```

```text
Z_6 的像 = [0, 2, 4, 0, 2, 4]   单射 = False
Z_7 的像 = [0, 2, 4, 6, 1, 3, 5]   单射 = True
```

$\mathbb{Z}_6$ 里 $2 \cdot 0$ 和 $2 \cdot 3$ 都等于 $2$，两种输入挤进同一个像，$2$ 就没有逆元；$\mathbb{Z}_7$ 里这张映射打满了全表，$2$ 的逆元是 $4$。差一格就没满射，这正是「有限」那一跳的具体形态。

域的例子不止 $\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$ 和 $\mathbb{Z}_p$（$p$ 为素数）。$A = \{a + b\sqrt{3} \mid a, b \in \mathbb{Q}\}$ 也是域：加法、乘法都封闭，加法群与分配律从实数继承，非零元逆元靠解方程组得到

$$\frac{1}{a + b\sqrt{3}} = \frac{a}{a^2 - 3b^2} - \frac{b}{a^2 - 3b^2}\sqrt{3}$$

分母 $a^2 - 3b^2 \ne 0$，因为 $a^2 = 3b^2$ 在有理数里无解（$\sqrt{3}$ 是无理数）；而 $a, b$ 有理，除出来的系数仍是有理数，逆元确实留在 $A$ 内。

## 九、同态：把结构保下来

前面都在一个结构内部看。同态处理的是结构之间：$A = \langle S, *, \triangle, k \rangle$ 到 $A' = \langle S', *', \triangle', k' \rangle$ 的映射 $f$，若满足

$$f(a * b) = f(a) *' f(b), \quad f(\triangle a) = \triangle' f(a), \quad f(k) = k'$$

就称 $f$ 是同态映射。三条式子说的是同一件事：**先运算再映射，和先映射再运算，结果一样**。运算、一元运算、常元各一条，一个都不能少。

按映射的性质分档：满射叫满同态，单射叫单一同态，双射叫同构（此时两个结构在代数上无法区分）；$A' = A$ 时叫自同态，再加双射就是自同构。

群同态只需要保一条乘法，其余自动跟上。以 $h: G \to H$ 为例，$h(e_G)$ 一定是 $e_H$：

$$h(e_G) = h(e_G \cdot e_G) = h(e_G) \cdot h(e_G)$$

在 $H$ 里消去一个 $h(e_G)$ 即可。同理 $h(a^{-1}) = h(a)^{-1}$，因为 $h(a) \cdot h(a^{-1}) = h(a \cdot a^{-1}) = e_H$。

同态里信息量最大的部分是**核**：$\ker h = \{x \in G \mid h(x) = e_H\}$。它是 $G$ 的子群，而且对任意 $g \in G$、$k \in \ker h$ 有

$$h(gkg^{-1}) = h(g)\, e_H\, h(g)^{-1} = e_H$$

所以 $gkg^{-1}$ 也在核里——核是正规子群，正好够用来做商群，于是有 $G / \ker h \cong \operatorname{Im} h$。同态把结构「压扁」，核度量的就是被压掉的那部分。

这套构造在一般代数系统上有个更朴素的说法。

称 $S$ 上的等价关系 $\sim$ 为**同余关系**，若它在所有运算下可保持：$a \sim b$ 则 $\triangle a \sim \triangle b$，$a \sim b$、$c \sim d$ 则 $a * c \sim b * d$。同态 $g$ 天然给出一个同余：$a \sim b$ 当且仅当 $g(a) = g(b)$。

有了同余，就能把等价类当成新元素，定义 $[a] *' [b] = [a * b]$，得到的 $\langle S/{\sim}, *', \triangle', [k] \rangle$ 叫商代数。这里唯一要担心的是**良定义**：换一个代表元，$[a*b]$ 会不会变？同余条件保证不会变，这也正是「同余」比「等价」多要求运算保持的原因。

从阶梯的角度回看，同态与商代数其实是同一件事的两面：同态把结构映射出去，商代数把结构折叠起来，第一同构定理说这两条路的终点是同一个。

## 十、小结

- **阶梯只有一条主线**：封闭 → 结合 → 幺元 → 逆元，对应代数系统、半群、独异点、群。判定顺序固定，后一条依赖前一条。
- **封闭性不是废话**：$\langle \mathbb{N}, - \rangle$ 连代数系统都不是，因为 $3 - 5$ 掉出了载体。
- **有限半群里每个元素都有幂等幂**，靠鸽巢；这条在 $A^A$ 的 4 个函数上肉眼可验，取反函数 2 次幂幂等。
- **幺元只需验一侧**：左幺元与右幺元同时存在则相等，$e_l = e_l * e_r = e_r$。
- **群的四条性质都靠左乘逆元推**：逆元唯一、幂等元唯一、消去律、$|G|>1$ 时无零元。群表每行是置换，实测 $\mathbb{Z}_5$ 五行全为置换。
- **子群判定可以省**：非空 + 封闭 + 逆元两条即可；写成 $a b^{-1} \in H$ 一条也行；**有限子集只要封闭**就够。
- **两个运算才配得上环与域**：$\mathbb{Z}_n$ 加法对任何 $n$ 成群，乘法永远有幺元 $1$，但合数一出现零因子，非零元就成不了群。$\mathbb{Z}_9$ 有 6 个可逆元，照样不是域。
- **有限整环必为域**，全靠「有限集上单射即满射」；$\mathbb{Z}$ 是整环不是域，缺的正是这一步。
- **同态 = 先算再映射等价于先映射再算**，核是正规子群，商代数把同余类折叠成元素，两者是同一条路的两端。
