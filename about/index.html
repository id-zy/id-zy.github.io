一纸墨痕

在算法与湖畔之间，寻找生活的源代码。

「笺札」是旧时书信的名字。这里是我寄给自己的信——写完封好，隔些日子再拆开，看看那时的自己站在哪里、望着什么。

一、此卷所载

不是作品集，是一份还在生长的手稿。截至今日，四百六十余篇，分作十一处：

卷目 篇数 所记何事
题目 373 算法与数据结构题解，兼有 SQL 题库
博客 30 Java 十二讲 · SQL 六讲 · 数据结构十一篇 · BI 入门
读书笔记 23 《社会心理学》《意识的解释》的章节拆解
离散数学 12 群、环、域、同态，代数的骨架
微原 7 8086 的时序、总线与最小最大模式
创作 6 影评与散文，写给十年前的自己
复习笔记 5 操作系统、计算机网络、数据挖掘
data mining 5 决策树、朴素贝叶斯、属性测试条件
项目 2 算术编码实验、软件需求规格说明书
计算机视觉 1 点算子
Python 1 面向对象与依赖管理

数字会变，方向大概不会。

二、所习

算法与数据结构 — 老战场。三百七十余道题，从哈希映射到字符串匹配，从双指针到动态规划。近来不再满足于「做出来」，而是把散落的招式收拢成册：十种排序、六种字符串匹配、二叉树的四种遍历，各成一篇，讲清它凭什么成立、该在什么场合出手。

SQL 与数据 — 新的主线。窗口函数如何在不分组的情况下排名、CTE 与子查询怎样与 TopN 配合、一条 SELECT 的真实执行顺序、索引为什么有时不被选中、事务的隔离级别换来换去究竟在换什么。写的都是做分析时真正会绊住脚的地方。

BI 与分析思维 — 正在入门。指标体系怎么搭、同比环比与留存怎么算、Tableau 如何把一张表变成一个能讲清楚的故事。技术之外，开始学着问「这个数字对谁有意义」。

计算机系统与工程 — 从硅底向上。8086 的时序、操作系统的进程与调度、计算机网络的层层封装，试图把这条栈从头走到尾，而不是停在某一层。Java 十二讲（从第一个程序到 Stream）与两个项目（算术编码、需求规格说明书），是把代码放进真实约束里的练习：有验收标准，有别人要读。

数据挖掘与视觉 — 新开的荒地。决策树怎么选最佳划分、朴素贝叶斯凭什么「朴素」、图像的点算子如何改写一张图，都还没走完。

知识管理 — 深度使用 Obsidian 构筑第二大脑，把离散的卡片连成网络。这座博客，本就是从那座库里长出来的。

三、所读

  • 《社会心理学》（戴维·迈尔斯）— 从众、偏见、认知失调、自我服务偏差。读它像照镜子，照见自己那些不肯承认的自动反应。

  • 《意识的解释》（丹尼特）— 多重草稿模型、笛卡尔剧场、缸中之脑。它没有给出答案，却拆掉了我提问的方式。

  • 《原则》 — 关于如何把经验压成可复用的判断。

  • 《瓦尔登湖》 — 梭罗问：我们是按照自己的想法过生活，还是随波逐流？

  • 《我与地坛》 — 史铁生答：活在自己的生活里、尊重自己的生活，才是最好的选择。

  • 《思考，快与慢》 — 卡尼曼给的一副透镜，用来警惕直觉的陷阱。

阅读的疆域在文学、心理学、哲学与社会学之间游走，都是为了理解技术之外，人之为人的其余部分。

四、所记

  • 影评与散文 — 在《普罗旺斯的夏天》里看亲情与回归，在《无姓之人》里沉思选择与可能，在《徒手攀岩》里看见「登顶之后，来路的荆棘已开满玫瑰」。

  • 技术笔记 — 学习路径的沉淀。写下来才算真懂，这是对自己唯一的硬要求。

  • 日记 — 退回私人笔记库，不再逐日公开。有些话留着给自己看更合适，能拿出来成文的，才放进这里。

五、所信

简单而非简朴 — 向往梭罗式的本真，追求精神的丰盈，而非物质的堆砌。

活在当下 — 让生活回到本来的样子。在课业与求职之间，守住内心的安静与专注。

保持好奇 — 从脑机接口到社会心理学，凡是未知，都值得推门看一眼。

「日出未必意味着光明。太阳也无非是一颗晨星而已。」

于我而言，真正的破晓，发生在每一个主动思考、认真生活的瞬间。
